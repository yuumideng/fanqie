# 《雪鹰领主》剧情迁移至《莽荒纪》世界：规则与总设定

> 版本：v0.1，第一版基准层。
>
> 核心方法：完整保留《雪鹰领主》的剧情功能和升级阶段，再用《莽荒纪》的世界层级、修炼称谓、神魔生命观和混沌地图承载它。

## 一、原作体量与迁移边界

| 项目 | 《雪鹰领主》 | 《莽荒纪》 | 迁移判断 |
|---|---:|---:|---|
| 篇/卷数量 | 38篇 | 45卷 | 不机械一篇对应一卷，按原作38篇保留节奏 |
| 章节数量 | 1384章 | 1450章 | 章节总量接近，适合做完整结构迁移 |
| 非空白字符数 | 约359万 | 约420万 | 新大纲保留原作信息密度，必要时用莽荒地图补足后期展开 |
| 前期地图 | 夏族世界、神界、黑暗深渊 | 三界、大夏世界、混沌世界 | 改为三界诸世界与大夏神朝体系 |
| 中期地图 | 神界、湖心岛、初始之地、母祖教宇宙 | 混沌海、古修遗迹、异宇宙、无尽混沌 | 按功能分层，不把中后期压回三界 |
| 后期地图 | 魔山宇宙、始祖魔山、界心大陆、修行圣界 | 异宇宙、起源之地、混沌源海、浑源圣界 | 完整开放终局地图，承载浑源生命和领主篇 |

## 二、迁移原则

1. **剧情顺序优先。** 保留38篇的主要事件先后、高潮分布、人物关系和结局方向。
2. **人物一一对应。** 新小说正文不用原作姓名；如一个角色承担多个功能，必须在角色表中拆分边界，不能临时更换身份。
3. **目标世界本土化。** 科幻、神界、宇宙组织改写为三界、混沌世界、道宫、异宇宙、起源之地等莽荒式结构。
4. **力量来源可追溯。** 顾长风的每条力量路线都必须有家族、血脉、传承、分身、遗迹或修炼实践来源，不能凭空增加金手指。
5. **地图逐级开放。** 三界只负责前期家乡和族群根基；中期进入混沌海与异宇宙，后期进入界心大陆、修行圣界和浑源层。
6. **保留原作爽点结构。** 重点保留真意领悟、越级战斗、公开排名、强敌围杀、传承考验、道果突破、救亲人和终局反杀。
7. **篇末必须有出口。** 每篇都要明确当前地图、境界、主要关系变化、已完成主线和下一篇入口。

## 三、新小说核心设定

### 3.1 主角与家乡

- **主角：顾长风。** 出身三界边缘的大夏世界，早期是雪石城附近的小家族少年，擅长枪术，识海中有极强的虚界感知天赋。
- **妻子：苏清。** 出身大夏世界的修行家族，早期是顾长风并肩执行任务的法修，后掌握时间、冰霜和心力路线，成为唯一正妻与长期道侣。
- **弟弟：顾岩。** 顾长风的亲弟弟，早期因心魔和家族纠纷受伤，承担兄弟情感与家族守护线。
- **初始目标：** 保护父母、救回顾岩、守住家族和雪石城。
- **中期目标：** 守护大夏世界和三界人族，阻止深渊、古修教派和外来宇宙势力吞噬家乡。
- **后期目标：** 追求自身大道，理解虚界与毁灭的本质，最终在浑源层保护整个源世界并复活至亲。

### 3.2 三界本土组织

| 原作功能 | 新小说处理 |
|---|---|
| 夏族超凡组织 | 大夏道宫：大夏世界最高修行组织，管理超凡、天神和真神传承 |
| 薪火宫 | 薪火神殿：三界人族的战争中枢与镇族神器所在 |
| 血刃神廷 | 血河神宫：混沌海人族联盟的最高道统与任务中心 |
| 时空神殿 | 太虚时殿：掌控时空、因果和跨界任务的古老势力 |
| 魔神会 | 深渊魔盟：黑暗深渊中联合诸多魔神的战争组织 |
| 母祖教 | 母源教：来自异宇宙的外来教派，试图以祭坛改写三界本源 |
| 湖心岛 | 赤心古岛：古修传承、真神器和虚界秘术的遗迹世界 |
| 太虚天宫 | 太虚道宫：混沌虚空中的修行者联盟，提供典籍、任务和排名 |
| 万界楼 | 万界楼：中立交易与刺杀组织，不直接归属任何族群 |
| 界心大陆 | 界心原陆：一座拥有独立本源和转世规则的超大型混沌大陆 |
| 修行圣界 | 浑源圣界：修行者与浑源生命争夺资源、尸骸和生存资格的终局地图 |

### 3.3 主角多路线与爽点来源

1. **表面路线：枪道。** 顾长风从家族枪术和大夏道宫基础传承起步，以枪法作为最稳定、最公开的战斗路线。
2. **第一隐藏路线：虚界真意。** 来源于识海天赋、赤心古岛传承和顾长风对虚幻世界的长期观察，先用于探查和保命，后成长为虚界道与虚界本源。
3. **第二隐藏路线：神魔炼体。** 来源于顾家血脉和黑风渊中的远古神魔遗蜕，解决肉身承载不足的问题。
4. **第三隐藏路线：行者传承。** 来源于黑葫芦中的古修传承，负责空间行走、破界传送和跨宇宙生存。
5. **第四路线：杀戮与毁灭。** 不是凭空附加，而是在血魔卷追杀、魔山宇宙战争和亲友陨落后，由顾长风把枪道、虚界和心境转化出的攻伐大道。
6. **后期心境路线：我心为天心。** 来源于顾长风长期守护众生、观察弱小者被屠戮和最终承担源世界命运的选择，用于连接个人大道与源世界本源。

## 四、关系硬约束

- 顾长风与苏清是唯一主感情线；柳月是早期虚假情感与识人线，姜容是顾岩感情线中的危险人物，不能与苏清合并。
- 顾岩是顾长风亲弟弟，早期受伤、后期修炼和婚姻都要持续存在，不能只作为前期动机。
- 岳沉、白烈是前辈同道；陆玄是早中期正式师尊；玄苍是高层导师；赤岳山主和石尘承担后期不同阶段的传承功能。
- 白灵是赤心古岛器灵，不是女主，也不进入感情线。
- 顾长风的虚界本尊、神魔本尊、影杀分身和浑源分身必须属于同一主意识，但各自承担不同地图和战斗功能。
- 结尾复活父母、弟弟、苏清及重要故人，复活必须由源世界和浑源层规则解释，不能无条件重置死亡。

## 五、输出格式

每篇按《雪鹰领主》原作的章节范围和节奏整理，包含：

1. 篇名、原作章节范围和迁移后地图；
2. 3—7个详细剧情段落；
3. 顾长风的境界、枪道、虚界、神魔炼体、心境与分身变化；
4. 角色关系、女性角色落点和新人物首次登场；
5. 篇末结果、已回收伏笔和下一篇入口。

每个剧情段落都同时写清剧情事件、原作功能、本土化处理、人物关系、战斗或修炼爽点和结果。
