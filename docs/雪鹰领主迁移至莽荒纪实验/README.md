# 《雪鹰领主》剧情迁移至《莽荒纪》实验

> 状态：第一版已完成。
>
> 本实验保留《雪鹰领主》38篇的剧情顺序、升级节奏、主要冲突、地图扩张和终局结构；人物全部改名，世界名词、力量表现和组织形态按《莽荒纪》本土化。

## 文件导航

- `00_迁移规则与新设定总表.md`：实验边界、体量、主角、世界与总路线。
- `01_角色对照表_原作至新小说.md`：原作角色与新角色一一对应，正文只使用新名字。
- `02_地图路线与阶段表.md`：从三界凡俗到浑源圣界的完整地图开放顺序。
- `03_力量体系迁移表.md`：把原作的超凡、真意、神心、规则、道、宇宙神与浑源路线迁入莽荒体系。
- `04_38篇剧情功能迁移表.md`：每篇的原作功能、迁移后的目标和关键爽点。
- `05_篇级迁移大纲_待生成.md`：按《雪鹰领主》38篇节奏整理的详细篇级大纲。

## 使用边界

这是一次结构迁移实验，不是对两部作品进行逐句改写。左侧原名只用于研究、对照和审计；新小说正文、篇级大纲和新设定中统一使用新名字。
