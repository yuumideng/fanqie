# 《雪鹰领主》迁移至《莽荒纪》篇级迁移大纲

> 状态：第一版已完成；共38篇，按《雪鹰领主》原作篇幅和节奏展开。
>
> 说明：每个剧情点都保留原作的功能位置，再以大夏世界、混沌海、异宇宙、界心原陆和浑源圣界完成本土化。正文只使用新人物姓名。

## 第一篇 雪石枪鸣

**原作章节：1—26章；迁移地图：大夏世界·雪石城、黑风渊外围。**

### 1. 顾家少年与雪石城困局

顾长风出生在雪石城附近的普通修行家族，父亲顾烈常年替城中矿脉打造法器，母亲林兰经营一间小铺，弟弟顾岩却因幼年识海受创无法正常修炼。顾长风每日在家族演武场练枪，表面上只是一个悟性不错的万象境少年，真正的愿望却是赚到足够资源，替弟弟重新接续经脉，也让父母不再受家族长老支配。家族内部有人认为顾岩是废人，甚至准备把顾家祖屋和矿契交给旁支，这成为顾长风最早的家庭压力。

雪石城外的荒兽突然袭击商队，顾长风为保护同行的普通人被方家子弟方烈带人抛弃。濒死之际，他识海深处一枚自幼佩戴的黑色石片裂开，元神念力第一次感知到数百丈外的枪尖、落石和荒兽呼吸。顾长风没有把异常能力暴露出来，只凭枪法挡住正面攻击，再用一枚石屑从死角击穿方烈的护腕，第一次完成“公开枪术压制、隐藏念力补刀”的战斗。

### 2. 雪石枪法与黑铁令

顾长风进入雪石城最好的武院修炼，接受基础枪术、神魔炼体和元神观想。教习发现他肉身、反应和识海感知都异常出色，却只把他当作适合枪道的少年。顾长风在公开训练中只展示祖传的雪石枪法，夜里却用念力操纵十六枚铁针，研究怎样让元神力量和枪锋形成同一条攻击线。

一次城中黑铁令争夺战，方家以家族势力压制所有散修，想独吞进入龙山楼遗迹的名额。顾长风故意把枪法压在同境水平，等方烈催动护体法宝、身体重心改变的瞬间，用元神念力让脚下碎石偏移半寸，随后一枪点中对方气海。雪石城龙山楼分楼主司安看出他的战斗并非单纯力量强横，授予他一枚黑铁令，邀请他接触更高层的任务体系。

### 3. 猎荒队与第一次守护选择

为了获得顾岩需要的生命灵药，顾长风加入高岑率领的猎荒队，和陈岳、魏石、魏青山进入荒野。队伍第一次遇到荒兽潮时，顾长风提前感知到兽群的真正目标不是灵矿，而是藏在地下的幼兽巢穴。他没有抢先夺宝，而是带队绕路救出被困的凡人村落，因此错过了最值钱的兽卵，却得到高岑等人的真正认可。

虎牙猎荒队为了抢夺远古兽卵，故意把三头荒兽王引向顾长风所在的废城。高岑重伤，其他队员被逼入死角，顾长风以枪法正面牵制最强荒兽，再让念力穿过地缝切断第二头荒兽的腿部经脉，最后以雪石枪法“落雪”击杀兽王。战后他把自己暗中御物的功劳推给队伍配合，继续维持“枪法天才”的表面身份。

### 4. 墨河洞天的黑色令牌

顾长风在废城深处得到一枚远古兽卵和一件残破神魔战甲，兽卵的生命波动与他的识海异常契合。方烈家族得知消息后派人截杀，顾长风被迫从三号荒城一路逃回雪石城，在连续厮杀中悟出“静潮”枪意：枪锋看似停滞，真正的杀机却从对手识海内部爆发。他反杀追兵，但也因此被方家公开悬赏。

司安从悬赏中发现黑铁令和兽卵都与墨河洞天有关，提醒顾长风不要把它们交给任何家族。顾长风把神魔战甲交给高岑换取救命资源，将大部分收益交给父母和顾岩，自己只留下足够修炼的部分。篇末，他向顾岩承诺一定会找到能治好弟弟的生命道果；同一时刻，黑色令牌在他掌心浮现“墨河洞天”四字，岳沉亲自来访，邀请他进入天极武院核心院。

**篇末状态：** 顾长风万象境巅峰，元神念力初醒，枪法形成静潮之意；顾岩仍无法修炼；黑铁令、吞星兽卵和墨河洞天成为下一篇入口。

## 第二篇 雷潮救亲

**原作章节：27—55章；迁移地图：大夏世界·青河郡、东香湖、雷潮涯。**

### 1. 黑铁令背后的父母线

顾长风进入天极武院核心院后，司安查到顾烈和林兰并非普通工匠夫妇。林兰年轻时曾是古老修行家族的旁支弟子，因为拒绝一桩政治婚约逃入大夏世界，后来被家族抓回并囚禁在雷潮涯；顾烈为了救她，主动进入东香湖炼器坊服苦役。顾长风得知父亲常年受旁支折磨、母亲在雷潮中以神魂抵抗禁制后，第一次明确把修行目标从“救弟弟”扩展为“救回父母”。

司安告诉他，只有积累足够龙山楼功劳、得到荣誉侯爵身份，才能迫使那个修行家族停止惩罚。顾长风没有冲动闯入雷潮涯，而是先拿出全部积蓄托人把顾烈调入法器总坊，避免父亲继续被折磨，再把剩余时间用于提升实力。这个选择保留了原作“先救急、后磨刀”的节奏，也让顾长风第一次学会在情绪和大局之间做取舍。

### 2. 青河郡任务与临时队伍

顾长风接下黑铁级任务，前往青河郡调查曲泰城卢家暗中供奉深渊魔神的分坛。队伍由司柏荣、梁雍、唐熊以及法修苏清组成。苏清出身修行家族，擅长冰霜法术和时间减速，她最初只把顾长风当作枪术不错的年轻队员，却在飞舟遇袭时发现顾长风能提前判断敌人的空间落点。

任务途中，顾长风在冷琼山斩杀八名劫修，故意不使用念力，借此确认自身纯枪法已经足以与紫府级强者正面厮杀。抵达曲泰城后，队伍攻入卢家分坛，表面上只是清剿魔神信徒，实际上却被称号级神使仇凡设局。唐熊、梁雍和司柏荣先后战死，苏清被冰霜领域困住，顾长风终于不得不展露部分元神感知。

### 3. 雷潮爆炸与天人合一

仇凡以血斧神通压制全队，顾长风先用枪法拖延，再以元神念力控制三柄短刃从背后刺入仇凡护体神光，最终正面一枪贯穿其胸口。卢家老祖卢怀如启动自爆，整座分坛化成火海，顾长风以自身神魔炼体硬抗冲击，把苏清从爆炸中心救出。两人在废墟中并肩撤离，苏清第一次意识到这个看似冷静的年轻人会把所有危险留给自己。

回到雪石城后，顾长风因父母和弟弟的压力无法真正静心，直到在城堡屋顶听见顾岩痛苦的梦呓，才明白自己一直把亲情当成必须完成的任务，而非真正理解家人的恐惧。他重新观察雪石城的风、雪和阵法波纹，枪意不再只追求穿透，而是与天地元气自然相合，终于达到天人合一。天地力量滋养肉身，他的枪法和元神同时蜕变。

### 4. 柳月退场与雷潮救援计划

柳月曾在顾长风少年时期以陪伴和温柔接近顾家，顾长风对她有过朦胧好感，却在天人合一后听见她和柳家兄长的谈话，知道她一直受命观察顾家资源，并把自己称作“只会练枪的武疯子”。顾长风没有纠缠，直接结束两人的关系，把这段虚假情感从主线中斩断。

司安同时查出姜容一家和深渊魔盟有联系。顾岩不相信哥哥的判断，认为顾长风因为柳月的事变得多疑。顾长风没有立刻强行拆散弟弟，而是把调查证据交给顾岩，让他自己选择。篇末，顾长风达到天人合一、接近银月层次，带着苏清和新的任务队伍前往雷潮涯营救林兰；顾岩则留在雪石城，姜容的真实身份成为下一篇的炸点。

**篇末状态：** 顾长风突破天人合一，枪法进入万物境门槛；苏清成为并肩伙伴；柳月退出主感情线；顾岩与姜容关系紧张；父母救援进入实质阶段。

## 第三篇 黑风渊战

**原作章节：56—71章；迁移地图：雪石城、黑风崖、黑风渊。**

### 1. 顾岩闯祸与兄弟决裂

顾岩和姜容在仪水城遭到地方世家子弟崔琥调戏，顾岩为保护姜容使用顾长风赠予的雷法符卷，误杀崔琥和一名军府骑士。崔家在地下悬赏组织发布高额追杀令，目标却从顾岩变成顾家全族。顾长风赶回雪石城后立刻调查姜容，发现姜家曾以邪神祭祀换取资源，姜容本人也多次向深渊传递顾家情报。

顾长风要求姜容三日内与顾岩断绝关系，顾岩认为哥哥只是因为修为提升就开始干涉自己的选择，两人第一次激烈争吵。顾长风没有解释自己查到的全部内容，只说“你可以恨我，但不能把命交给一个连来历都不愿告诉你的人”。兄弟关系由亲近转为裂痕，顾长风却始终安排暗卫保护顾岩。

### 2. 项魔追杀与雪石城夜袭

崔家悬赏吸引来项魔，一名以异兽血脉和杀戮秘术闻名的强者；姜家则派出风魔等刺客潜入雪石城。顾长风在夜袭中以天人合一感知整座城堡的空气变化，三枪击杀风魔和两名刺客，却发现项魔本人已经站在顾岩房前，明确表示只杀顾岩，不会伤害其他人。

顾长风挡在弟弟面前，拒绝交出顾岩。项魔收回护体神通，把力量压到与顾长风相近的层次，两人从雪石城一路追到黑风崖。顾长风公开只使用枪法和神魔炼体，数次被逼到绝境，关键时刻用微弱念力改变枪身角度，令项魔误判三次。苏清想要支援，却被顾长风以传音阻止，他知道这场战斗不是普通围杀，而是顾家兄弟能否重新互相信任的转折。

### 3. 黑风崖绝杀与万物境突破

黑风崖下方是吞噬一切元气的黑风渊，项魔在斗气耗尽后显露出四蹄黑甲的异兽真身，力量骤增。顾长风被一爪打碎胸骨，顾岩却在姜容的催促下没有逃走，反而用初学的阵法替哥哥挡住一击。顾长风看到弟弟终于没有把自己当成必须依靠的废人，心中长期压抑的怒火和保护欲同时爆发。

生死一刻，顾长风把水火风三种枪意压缩成一点，枪锋不再追求范围，而是追求穿透万物之间最薄弱的缝隙。他以火焰短枪三次连射贯穿项魔头颅，正式悟出万物境的极点枪意。项魔陨落，顾长风却被黑风卷入深渊，顾岩抓住他的手臂只坚持了几个呼吸，兄弟在坠落中诀别。

### 4. 坠渊悬念与姜容真面目

顾长风坠入黑风渊深处，看到渊壁上盘踞着一头千丈黑色古兽，古兽体内有与吞星兽卵相同的生命波动。黑风没有杀死顾长风，而是把他卷入一片时间流速异常的地底世界。顾长风最后留下的念头不是“杀姜容”，而是让白灵保护顾岩和父母。

雪石城众人以为顾长风已经陨落，姜容却在无人处露出真实面目，试图夺走顾家遗物献给深渊魔盟。顾岩听见这段话后终于明白哥哥的苦心，当场与姜容决裂，却被姜家强者掳走。篇末，苏清带人守住雪石城，林兰在雷潮涯中感知到儿子的生命印记尚未熄灭，顾长风则在黑风渊深处睁开双眼。

**篇末状态：** 顾长风达到万物境，击杀项魔后坠入黑风渊；顾岩确认姜容是敌人并被掳走；黑风渊古兽和吞星兽卵出现血脉关联。

## 第四篇 渊底六年

**原作章节：72—99章；迁移地图：黑风渊、墨河洞天、大夏道宫。**

### 1. 黑风渊中的六年修行

顾长风在黑风渊底发现一座由古神骨骸形成的洞窟，时间流速比外界快了数百倍。黑色古兽并非敌人，而是远古神魔遗留下的守门生命，它以黑风磨炼顾长风肉身，逼他在没有法力、没有法宝的情况下只凭枪意活下去。顾长风每天承受骨骸风暴，神魔炼体从万象层次突破到元神道人层次，身体逐渐具备不死恢复能力。

白灵通过残缺令牌与顾长风建立联系，告诉他外界已经过去六年，顾岩被救出但识海留下深渊烙印，顾烈和林兰的救援也被迫暂停。顾长风没有急于冲出，而是把黑风渊的每一道风痕记录在识海中，终于从风的无序变化里悟出“虚界感知”的雏形：他能在真实世界外侧建立一层只属于自己的感知空间。

### 2. 神魔遗蜕与吞星分身

黑风渊最深处埋着一具远古吞星神魔遗蜕，顾长风若直接炼化，会被庞大的兽性本能吞噬。顾长风先以元神念力分出九道意识，分别承受遗蜕中的饥饿、毁灭、孤独和吞噬本能，最后只保留一缕最纯粹的生命意志。那缕意志与墨河洞天中的兽卵融合，孵化出吞星角兽分身。

吞星角兽分身没有独立人格，和顾长风共享主意识，却拥有远超人族本尊的肉身和吞噬能力。顾长风因此得到第二条隐藏路线：人族本尊继续修炼枪道和虚界，吞星角兽分身则吞食黑风渊中的混沌残骸，反哺本尊肉身。多路线第一次真正建立来源和边界。

### 3. 家族团圆与大夏道宫选择

顾长风脱离黑风渊后回到雪石城，发现顾岩已经不再等待别人救治，而是开始学习阵法和元神法术。姜家被大夏道宫审判，姜容被深渊魔盟带走，成为后续敌人的线索。林兰从雷潮涯救出，顾烈结束苦役，顾家终于团圆，但父母都已受损严重，无法再恢复年轻修为。

顾长风拒绝几个古老势力的招揽，选择加入大夏道宫。苏清也通过法修考核进入同一道统，两人确定了共同修行和共同守护家乡的关系。顾长风把吞星角兽分身隐藏为远古神魔遗脉，只有白灵、岳沉和陆玄知道真相。

### 4. 超凡入门与薪火资格

大夏道宫为顾长风安排六大超凡组织考核，他在水源道观的水火试炼中创出“水火蛟龙枪”，以元神感知让两条蛟龙从不同方向同时穿透敌阵。之后他参加超凡生死战，连续击败九名同阶强者，最后一战故意不用吞星分身，只以枪道和虚界感知获胜。

顾长风因此进入薪火神殿候补名单，开始接触三界人族真正的战争资料。他得知黑风渊并非孤立灾难，大夏世界边缘正在出现大量通往黑暗深渊的裂缝。篇末，苏清在薪火神殿的镇族神器前引发共鸣，白发器灵“雪前辈”选择她作为未来主人；而顾长风收到赤云山候补元老试炼令。

**篇末状态：** 顾长风脱离黑风渊，形成吞星角兽分身，进入超凡层次；顾家团圆；苏清被镇族神器选中；三界战争即将开启。

## 第五篇 薪火神殿

**原作章节：100—130章；迁移地图：薪火神殿、夏都城、超凡战场。**

### 1. 夏都城的候补资格战

顾长风抵达夏都城，发现薪火神殿并不是单纯的修炼圣地，而是一座以镇族神器守护三界人族的战争堡垒。候补元老按照排名获得秘境、功劳和生死任务，顾长风被安排与都柔柔、司徒鸿、卓宁等天才竞争。司徒鸿擅长空间裂痕，表面谦和，实际上习惯用规则和人情排挤新人。

血河帝君得知顾长风开辟虚界道后，既震惊又担心他过早暴露。帝君赐下虚空魂液，帮助顾长风把本尊神心蜕变速度提升十倍，并要求他进入六道天轮接受任务。顾长风把自己伪装成普通四重天界神，只公开世界、混洞和极点三种道果。

顾长风用虚界道把血蛇枪、真神器飞刀和黑雾帝君法印全部隐藏在一层幻境中，只有苏清和血河帝君知道真正底牌。临行前，他将黑雾海防务交给白行舟和顾岩，自己带吞星角兽分身进入血魔洞天。

顾长风初战斩杀蛏云护法，血蛇枪的血毒和虚界飞刀配合，令对方无法通过分身复活。随后，他以幻境活捉盅蛇护法，从其灵魂中得到母源教老巢大致星图。盅蛇护法在幻境中自毁灵魂，顾长风却没有继续搜魂，避免让虚界道沾染过多因果。

### 3. 三魔殿考验

顾长风在六道天轮中进入溶血殿、蚀骨殿和炼心殿。溶血殿要求他以血肉承受血兽吞噬，顾长风让吞星角兽分身分担兽性，万年内完成溶血秘术；蚀骨殿则以骨骼崩碎考验神魔炼体，他以万劫混元体重铸骨骼；炼心殿最后考验心意如刀，任何仇恨和恐惧都会成为反噬。

三种秘术完成后，顾长风得到《万魔真身》初始卷和一张古塔星图。万魔真身让他的血肉、元神和分身可以重新换血换骨，身体强度大幅提升。顾长风意识到，这正是自己从虚界道“保命极致”转向真正正面攻伐的关键。

### 4. 杀戮道与新的三祖

顾长风闭关八百多万年，观察血魔洞天中无数生命在吞噬和被吞噬之间挣扎，终于把毁灭枪中的杀伐本质独立出来，开辟第二条大道——杀戮道。青君和苦行者帮助他搜集外物，顾长风炼成万魔真身初始卷。

庞依突破主宰，慧明大师拜师成功，混沌海高层开始议论“新的三祖”。万花宴上，毁灭君主公开支持顾长风，血河帝君则把宇宙石心和分身法交给他，并将他推到新的三祖候选位置。顾长风没有沉迷封号，只提出尽快救白行舟和查清母源教老巢。

**篇末状态：** 顾长风开辟杀戮道，炼成万魔真身，进入新的三祖格局；母源教老巢范围被锁定；顾长风开始拥有与主宰正面抗衡的底牌。

## 第二十二篇 古葫芦传承

顾长风在万花宴后收下迦云和魔冲云为内门弟子，分别负责虚界感知和杀戮枪道的初步传承。顾岩担心他收徒过多会分散精力，顾长风解释，真正的传承不能只留在自己一人身上，尤其是在母源战争即将爆发时。

他循着魔祖留下的古星图进入虚空河流，经过五千三百年寻找，抵达一个与外界完全隔绝的隐秘古界。顾长风化名“飞雪”加入崇氏世家，收崇言为弟子，开始观察这个世界的修行和权力结构。

### 2. 崇氏世家与绯火宫

隐秘古界中，天火宫执法使以维护秩序为名吞噬小宗门，崇氏世家不敢反抗。顾长风没有立刻亮明身份，而是以飞雪身份教授崇言枪法和虚界感知。崇言从只会依赖家族资源的少年，逐渐学会用自己的判断保护族人。

天火宫派人索取崇氏祖传宝物，顾长风以《截杀六剑式》第一次公开出手，六道枪痕封锁六处退路，斩杀执法使。绯火宫主亲自降临，顾长风用万魔真身硬抗其火焰，最终以虚界幻境让对方误入自己的火海，完成越级击杀。

### 3. 古神殿三重考验

顾长风在隐秘古界深处发现古神殿，以巨力抬起石门，登上九千九百九十九级阶梯。古神殿守护者是一名虚空行者，要求他通过三重考验：第一重承受空间撕裂，第二重悟出黑葫芦操纵法，第三重接受心性审查。

顾长风五年内通过前两重，第三重却迟迟无法完成。黑葫芦器灵让他选择一件最重要的东西交出，顾长风没有交出苏清、顾岩或家乡，而是交出“我必须亲自保护所有人”的执念。器灵因此认可他，黑葫芦开始真正认主。

### 4. 七门半绝学与回归

顾长风在隐秘古界停留数万年，收集七门半绝学，分别补足虚界、杀戮、空间和毁灭四条路线。崇言成长为界神后，顾长风没有把他带走，而是让他在古界建立自己的道统。师徒告别时，崇言第一次喊顾长风为师父，而不是飞雪前辈。

顾长风施展黑葫芦撕裂世界膜壁，返回混沌海。青君成功突破主宰，顾长风借黑葫芦器灵探查十位主宰的灵魂排名，发现母源教正在把大量护法送入一艘洞天飞舟。血河帝君召集三十六位尊者，母源战争前线即将开启。

**篇末状态：** 顾长风完成隐秘古界化名行走、收徒和黑葫芦认主前置；得到行者传承入口；母源教洞天飞舟进入混沌海。

## 第二十三篇 母源飞舟

血河帝君率三十六位尊者进入母源洞天飞舟，顾长风作为未成主宰的特殊战力留在第二梯队。飞舟内部每一层都由母源祭坛控制，三重幻境先后吞没十二名母源教护法。顾长风用虚界感知找出幻境重叠点，把敌人引入彼此的幻境中。

双方在两天内发生上百次搏杀，母源教护法数量不断下降。顾长风表面上只使用万魔真身和杀戮道，暗中让黑葫芦吞食飞舟边缘的混沌火种。黑葫芦器灵不断提醒他，飞舟真正的主人正在苏醒。

### 2. 骨乾罗与红光区域

洞天飞舟主人骨乾罗苏醒，指出母源教建立母源祭坛是为了把异宇宙本源投射进三界。他不相信血河神宫，也不愿把全部力量交给母源教，于是划定红光区域，要求双方各自选出帮手争夺。

红光区域中，顾长风与三名母源教圣护法交手。寂灭大帝以异宝轰出毒钩尾巴女子，敌方梭状兵器却在最后一刻将其反杀。顾长风用虚界道救下寂灭大帝，再以黑葫芦吸走红光区域的一部分本源，成为骨乾罗重点观察的候选帮手。

竹山道君的残余分身在关键时刻破坏黑暗漩涡法阵，导致母源教得到飞舟控制权。血河帝君亲自斩杀其本尊，竹山道君的一具分身投靠母源教。顾长风没有因此前仇而欣喜，反而意识到战争中最危险的不是正面强敌，而是被利益和恐惧改变的熟人。

顾长风炼化黑葫芦，释放其中的黑色火球，连续灭杀母源教所有护法。五位教主联手偷袭，黑葫芦中的行者护体挡住致命一击，顾长风重伤却保住本源。血河帝君追杀教主，母源教不得不暂时退入飞舟深处。

### 4. 行者传承与异宇宙通道

黑葫芦器灵告诉顾长风，真正的古修传承来自“古奇”，一位曾经穿越异宇宙的虚空行者。顾长风通过心性考验，接受《行者秘藏》第一层，学会把自身存在折叠到世界膜壁缝隙中。

太虚殿主在飞舟边缘发现一条小型宇宙通道，母源教正在利用它召来外宇宙力量。顾长风独自进入通道，临行前让苏清和白行舟留在血河神宫保护家乡。通道另一端传来一座陌生魔山宇宙的气息。

**篇末状态：** 母源飞舟初战结束；顾长风炼化黑葫芦、得到行者秘藏第一层；异宇宙通道开启，魔山宇宙成为新地图。

## 第二十四篇 魔山岁月

### 1. 魔山宇宙化名行走

顾长风派分身进入魔山宇宙，发现这里的时间流速是家乡混沌海的三千多倍。他化名顾东，加入三殿下护卫队，从最低层修行者开始观察这个宇宙的权力结构。黑葫芦和行者秘藏被隐藏在灵魂最深处，公开路线只展示杀戮枪法和万魔真身。

三千万年修炼中，顾长风把波动道从空间行者体系中独立出来，自创“道风波”，并将行者秘藏推到第六层。波动道让他的枪法不再只穿透一点，而是能让敌人的整个力量体系产生共振，成为越级挑战的关键。

### 2. 尊者击败主宰

大殿下带红魔神帝抢夺黑魔圣果，魔山宇宙各方势力都认为三殿下必败。顾长风以飞镖先灭杀十二名护卫，再用杀戮领域压制红魔神帝的主宰规则。红魔神帝以宇宙本源碾压，顾长风则用波动道让本源力量在每次传递时产生偏差。

最终，顾长风以尊者境界击败红魔神帝，夺回黑魔圣果。魔山宇宙各方震动，三殿下邀请他共享权力，顾长风却只要求进入始祖魔山的资格，因为那里有可能让行者秘藏突破更高层。

### 3. 始祖魔山外层挑战

蛟云大帝赠给顾长风《万物图录》，送他前往始祖魔山。外层考验分别是水傀儡、雪神尊者和猎殃尊者，顾长风先用波动道破解水傀儡，再以虚界幻境让雪神尊者自陷寒冰世界。

六百万年后，顾长风击败猎殃尊者，成为始祖魔山外层最强尊者。与此同时，母源教与家乡修行者宇宙的战争全面爆发，血河帝君多次战死，八万余年后顾长风在始祖魔山内层沉入梦境。

### 4. 梦中修行

始祖魔山内层的梦境不是幻术，而是一座把修行者意识送入无数世界的古修秘境。顾长风在梦中经历凡人、神魔、君主和世界毁灭者的一生，把杀戮道、虚界道、波动道和行者秘藏全部重新拆解。

家乡混沌海的强者无法唤醒他，苏清只能通过镇族神器感知到他仍然活着。梦境持续六亿五千万年，顾长风终于把行者秘藏推到第十一层，跨入主宰门槛。篇末，他从梦中苏醒，母源战争已经进入最惨烈阶段。

**篇末状态：** 顾长风在异宇宙以尊者击败主宰，行者秘藏进入第十一层并接近主宰；家乡母源战争全面爆发。

顾长风从梦境苏醒后，以行者秘藏第十一层直接跨过普通道境，成为虚界行者一脉的主宰候选。他再次进入初始古地，通过冰晶、黑色水滴和黑色凶兽三重开辟境考验，成为太虚道宫紫衣弟子，选择三门混沌级基础绝学。

他把虚界道与杀戮道融合，悟出永恒完美的规则领域，正式成就主宰，超脱家乡源世界的时光长河。顾长风没有庆祝，而是立即返回战场，因为母源教正在利用十二元辰柱封锁家乡源世界。

血河帝君布置十二元辰柱，顾长风的一尊分身独自守住核心阵眼，抵挡母源教须木圣舟的冲击。骨乾罗背信投靠母源教，破坏元辰柱法阵，母源教趁机建立六座祭塔。顾长风以黑葫芦释放太阳金焰，夺下第一座祭塔。

骨乾罗偷袭黑葫芦失败，被黑色野狗吞噬九颗毁灭球体和混沌飞舟。黑色野狗告知顾长风，自己是远古守护者，不希望任何一方真正毁灭源世界。顾长风第一次发现，战争双方之外还存在守护源世界规则的古老生命。

### 3. 战争结束与亲人消散

血河帝君三体合一突破虚空神境界，母源教教主被迫退入异宇宙。顾长风以虚界道跨越两座宇宙，隔着本源让黑魔老祖的本尊和分身先后自杀，替古岛和大夏战争中的死者报仇。

战争结束后，顾烈、林兰、顾岩的寿元相继走到尽头。顾长风拥有主宰力量，却无法违背家乡源世界的生命规则，只能眼看亲人消散。苏清陪他守完最后一夜，顾长风把所有悲伤收进虚界深处，决定离开家乡，寻找真正能改变生命和死亡的道路。

### 4. 金衣弟子与混沌虚空

顾长风通过主宰级考验，斩杀百首吼上百个头颅，成为太虚道宫金衣弟子，得到一杆虚空神枪。三体合一后，他划开家乡源世界膜壁，飞入混沌虚空。

苏清留在家乡修炼时间道，白行舟负责太虚道宫和大夏世界的情报，顾玉和顾瑶开始承担家族传承。顾长风答应苏清一定会回来，也一定会找到让至亲真正复活的方法。篇末，顾长风的身影消失在混沌虚空深处，灭世三剑和太虚道宫新篇开启。

**篇末状态：** 顾长风成为主宰，母源战争阶段性结束；父母和弟弟相继消散；顾长风离开家乡源世界，进入混沌虚空。

## 第二十六篇 灭世三剑

**原作章节：780—817章；迁移地图：混沌虚空、沉餮大陆、太虚道宫、星辰塔。**

### 1. 混沌虚空赶路

顾长风在混沌虚空中潜修十亿年，参悟血河帝君传下的《灭世十三剑》枪剑化版本。第一式迟迟无法完成，他在虚空廊道中遭遇未知传送，被送到沉餮大陆。沉餮大陆有十六头主宰级虚空生物和三头虚空神，正在吞噬大陆本源。

顾长风化身降临沉餮大陆，没有急于寻找离开通道，而是先为大陆上的十万种族阻挡虚空生物。十万年守护中，他观察一座大陆如何在毁灭中维持生命秩序，终于悟出灭世第一枪：不是单纯摧毁，而是以毁灭斩断无法挽救的腐朽。

### 2. 罗海与天哭门主

离开沉餮大陆后，顾长风与一名叫罗海的混沌修行者结伴，横扫二百余座混沌陆地。两人对弱者的态度不同：罗海只看任务结果，顾长风则会尽量救出普通生命。天哭门主因此盯上他们，魔祖也现身杀死五名合一境修行者。

危急时刻，罗祖降临逼退骨祖和天哭门主。顾长风从罗祖口中得知超脱源世界有三条不同道路：本源融合、古修传承和浑源炼体。他开始意识到，自己不能只依赖虚界道，还必须为最终离开规则体系准备肉身和心境。

### 3. 太虚道宫典籍与真神排位

顾长风进入太虚道宫金衣弟子洞府，在万象殿翻阅三百二十三万年典籍，又在时光殿闭关三亿两千万年，把行者秘藏推到第二十一层，道风波也创出新篇。真神弟子排位战中，他只使用公开枪法杀进前十，最终获得第三名和拂灵心果。

拂灵心果让顾长风灵魂更加通透，他在星辰塔第一层却首次战败，发现主宰并不等于无敌。顾长风重新闭关五十八亿年，把虚界、杀戮和波动三大道推到虚空神门槛，悟出灭世第二枪和鱼龙杀。

### 3. 浑源领主之战

天生浑源生命杀岩带领六位世界级浑源圆满强者来袭，顾长风炼制浑源神兵，先以虚界幻境分割六人的感知，再用虚空道封锁他们的逃遁路线。浮甚、黑白无限之蛇等强敌连续发动本源冲击，顾长风的源世界分身和主战分身同时重伤。

生死关头，顾长风将虚界幻境究极与虚空道究极融合，彻底理解“世界之内的规则”和“世界之外的力量”可以在同一枪中完成闭环。他以力破法成为浑源领主，并将六位大敌分别封禁在六座虚界牢笼中，避免他们继续伤害浑源圣界。

### 4. 复活至亲与全书收束

元祖和罗祖现身迎接顾长风，向他解释浑源领主能够在源世界本源中追溯生命印记，但复活并非无条件重置：只有曾经留下道果、因果和被源世界记录的生命，才有机会重新凝聚。

顾长风回到家乡源世界，先复活顾烈、林兰和顾岩，再复活大夏战争中留下完整道果印记的岳沉、白烈、古奇等故人。苏清带着顾玉、顾瑶和鹤宁在雪石城外迎接他，白行舟则把重新修复的空间阵法铺满家乡。

顾长风没有把浑源领主之位变成新的统治，而是在大夏世界建立开放道宫，让任何愿意修行的人都能找到自己的路。小说最后，他和苏清站在雪石城最高处，看见曾经只能仰望的混沌星海。顾长风知道道路没有真正终点，但这一次，他身边有家人、弟子和整个源世界共同向前。

**全书终局状态：** 顾长风以虚界幻境与虚空道融合，以力破法成为浑源领主；深渊海主、圣主和毁灭魔族被灭；顾烈、林兰、顾岩及重要故人复活；苏清、顾玉、顾瑶、白行舟等人完成各自道路；大夏世界从家乡小世界成长为拥有完整道统的源世界。
