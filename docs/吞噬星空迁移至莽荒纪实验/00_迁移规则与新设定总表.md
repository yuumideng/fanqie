# 《吞噬星空》剧情迁移至《莽荒纪》世界：规则与总设定

> 版本：v0.1，基准层
>
> 本实验采用“完整剧情骨架 + 《莽荒纪》世界本土化”的方式。保留《吞噬星空》29篇的主要事件顺序、成长阶段、关键爽点和结局方向，但不直接照搬科幻名词、人物姓名或宇宙组织。

## 一、原作体量与迁移边界

| 项目 | 《吞噬星空》 | 《莽荒纪》 | 迁移判断 |
|---|---:|---:|---|
| 篇/卷数量 | 29篇 | 45卷 | 不按篇卷硬对应 |
| 章节数量 | 1485章 | 1450章 | 章节总量接近 |
| 非空白字符数 | 5,084,341 | 4,197,700 | 《吞噬星空》约多21% |
| 前期核心地图 | 地球与人类基地市 | 三界与大夏等世界 | 改为三界中的核心小世界/人族疆域 |
| 中期核心地图 | 初始宇宙、秘境、域外战场 | 混沌世界、永恒界、古域 | 按功能重新分配 |
| 后期核心地图 | 宇宙海、晋之世界、界兽巢穴、起源大陆 | 无尽混沌、异宇宙、起源之地 | 保留终局层级，改用莽荒词汇 |

## 二、迁移原则

1. **剧情顺序优先。** 29篇的阶段推进、主要转折和结局方向以《吞噬星空》为骨架。
2. **目标世界本土化。** 新小说正文不使用罗峰、徐欣、洪、雷神等原作人物姓名，也不直接使用虚拟宇宙公司、宇宙国、机械族等科幻组织名。
3. **功能优先于名词。** 如果原作的科技装置在莽荒世界无法直接存在，就迁移它承担的功能，例如交易网络、传承空间、情报系统、远程通讯或试炼场。
4. **境界不做机械等价。** 原作境界和莽荒境界不是一一相等，采用“剧情功能等价 + 目标体系主序”的方式处理。
5. **多路线必须有来源。** 主角的肉身、元神、心力、血脉、分身和特殊秘法，都要有传承、机缘、实践或本体结构上的来源。
6. **地图必须逐级开放。** 三界不是全书终点；主角需要经过混沌世界、域外势力、异宇宙和起源之地，最终完成终局超脱。
7. **所有未确认内容显式标记。** 角色和设定使用“已固定、功能位已定、待补写”三种状态，不允许隐性合并。

## 三、新小说核心设定

### 3.1 主角与家乡

- **主角：江川。** 出身三界边缘的玄星界，早期是普通武院少年，因精神感知异常和肉身悟性被发现，逐步走上神魔修行路。
- **家乡：玄星界。** 三界中的一个普通小世界，曾被远古大能改造为适合人族心境成长的“心源界种”。它外表普通，实则与远古生命道和心力传承有关。
- **主角初始目标：** 让弟弟江越重新站起来，守护父母和玄星界。
- **中期目标：** 保护玄星界不被大世界势力夺取，建立自身在三界和混沌中的立足之地。
- **后期目标：** 守护三界人族、对抗界兽级毁灭灾难，最终寻找自身道路并突破轮回。

## 四、关系硬约束

- 江川与沈宁是少年相识、共同成长、后期成婚的唯一主感情线；沈宁不承担师妹、退婚对象或临时替代女主功能。
- 江越是江川亲弟弟，早期残疾和后期成长必须持续存在，不能被删成一次性动机。
- 岳沉与白烈是江川的前辈和并肩者，不是江川的父亲或师尊；陆玄承担正式师尊功能。
- 白灵是器灵，不写成普通人族女性角色，也不进入感情线。
- 莫言留下的是早期传承和伏笔，石尘承担后期起源之地布局，二者不能合并。
- 吞星角兽、影杀分身是江川的不同分身/路线，不是两个独立主角。
- 墨罗是被江川收服的终局关键生命，不是早期反派的简单改名。

## 五、输出格式

每篇按《吞噬星空》原作篇章节奏编写，保留：

1. 篇名、原作章节范围和迁移后地图；
2. 3—7个详细剧情段落；
3. 主角境界、肉身、元神、心力和分身变化；
4. 人物关系和新角色首次落点；
5. 篇末的主要结果、悬念和下一篇入口。

详细剧情段落必须同时写清：原作事件、原作功能、本土化处理、人物关系、战斗/修炼爽点和结果。
