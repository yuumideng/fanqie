# 地图路线与阶段表

> 目标：保留《吞噬星空》从家乡崛起到超脱轮回的空间扩张感，同时使用《莽荒纪》的三界、混沌世界、异宇宙和起源之地作为新地图骨架。

## 一、总路线

玄星界 → 三界人族疆域 → 墨河洞天/太初秘境 → 血纹古界 → 古源秘境 → 三界边荒 → 混沌战场 → 寒狱界 → 祖灵殿 → 无尽混沌海 → 四大绝地 → 晋王遗界 → 灭界兽巢穴 → 起源之地

|---|---|---|---|---|

## 三、每个区域的固定设计字段

后续正式写地图时，每个区域必须补齐：

1. 进入原因；
2. 区域统治者和主要势力；
3. 进入门槛与主角当时境界；
4. 区域资源、传承和比赛/任务机制；
5. 主要敌人和长期竞争者；
6. 主角获得的能力、身份或盟友；
7. 离开时付出的代价；
8. 对下一地图和主线终局的影响。

## 四、与《莽荒纪》地图的关系

- 三界承担玄星界、地球文明和原始宇宙人族疆域的综合功能，但不等同于地球本身。
- 混沌世界、永恒界和异宇宙承担宇宙国、秘境、域外战场和宇宙海的层级功能。
- 四大绝地承担宇宙舟、倾峰界、流重山等高危遗迹功能。
- 晋王遗界承担晋之世界、远古文明和神王传承功能。
- 灭界兽巢穴承担界兽巢穴与终局毁灭危机功能。
- 起源之地承担起源大陆和最终超脱入口功能。
