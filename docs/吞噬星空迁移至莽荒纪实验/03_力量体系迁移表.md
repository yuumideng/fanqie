# 力量体系迁移表

## 一、总原则

《吞噬星空》的力量体系不直接改名复制，而是拆成四类功能，再接入《莽荒纪》的修行主序：

1. 肉身生命路线；
2. 元神、念力和心力路线；
3. 法则、兽神之道和大道路线；
4. 分身、洞天、世界和宇宙本源路线。

## 二、莽荒主序

> 后天 → 先天 → 紫府 → 万象 → 元神道人 → 天仙 → 纯阳真仙 → 天神/真神 → 世界境 → 道君 → 永恒帝君 → 主宰/至尊

原作境界只作为剧情参考，不与以上境界机械等同。具体篇章中采用“阶段功能等价”。

## 四、江川的多路线

### 4.1 表面路线：神魔炼体与刀道

江川早期在玄星界以肉身和刀法成名，进入天极武院后，逐步修炼雷霆、空间和杀伐类神魔体。他的公开战绩主要来自刀道、身法和近战，形成“同级肉身更强、战斗经验更丰富”的第一层爽点。

### 4.2 隐藏路线：元神念力与心力

江川早期因玄星界心源本质而提前觉醒元神念力，但公开场合只展示肉身和刀道。元神念力负责御器、感知、分心和远程攻击；心力则在长期战斗、守护家人和经历族群战争后逐步觉醒，形成第二层越级能力。

### 4.3 特殊路线：吞星角兽与影杀分身

- 吞星角兽：负责吞噬生命精华、强化肉身、参悟兽神道和承载特殊血脉秘法。
- 影杀分身：负责潜入、复制、探险和承担高死亡率任务。
- 无尽幽海身：中后期形成后，负责神力储备、生命创造和大型战争支援。

三条分身路线共享江川的核心元神，但各自有不同的战斗功能和成长代价，不能写成无条件叠加的外挂。

## 五、境界阶段表现

| 原作阶段 | 新小说主要境界 | 主角爽点 |
|---|---|---|
| 地球少年至战神 | 后天—先天—紫府—万象 | 肉身强、刀法快、元神念力隐藏越级 |
| 宇宙级至界主 | 元神道人—天仙—纯阳真仙 | 进入三界大势力，分身、秘境任务和道域逐步成形 |
| 不朽至宇宙尊者 | 天神/真神—世界境 | 从天才变成三界领主，凭多路线挑战高境界敌人 |
| 宇宙之主至真神 | 世界境—道君—永恒帝君 | 掌控世界、开创绝学、统领族群、对抗混沌海顶层势力 |
| 虚空真神至神王 | 永恒帝君—主宰/至尊 | 面对灭界兽和轮回终局，完成生命、毁灭和心力道路统一 |
