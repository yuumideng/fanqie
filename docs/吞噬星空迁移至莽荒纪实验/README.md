# 《吞噬星空》→《莽荒纪》剧情迁移实验

本目录用于将《吞噬星空》的完整剧情骨架迁移到《莽荒纪》的世界、力量和地图体系中。

## 当前迁移口径

- 保留《吞噬星空》29篇的主要剧情顺序、关键转折、人物功能和结局方向。
- 所有人物更换为新名字；原名只出现在对照表中，用于追踪迁移来源。
- 篇章节奏以《吞噬星空》原作29篇为准，不强行按《莽荒纪》45卷一一对应。
- 允许重新组织《莽荒纪》的地图，使三界、混沌世界、异宇宙、起源之地等区域承担原作中的地球、原始宇宙、宇宙海和起源大陆功能。
- 先完成迁移基准层，再写篇级大纲；基准层未锁定前，不进入详细剧情润色。

## 产物

1. `00_迁移规则与新设定总表.md`：迁移模式、世界重构、人物命名、关系硬约束和输出规则。
2. `01_角色对照表_原作至新小说.md`：原作主要人物与新人物的一一对应。
3. `02_地图路线与阶段表.md`：新小说从三界到混沌终局的地图开放顺序。
4. `03_力量体系迁移表.md`：科技、基因、念力、兽神之道等能力向莽荒力量体系的本土化方案。
5. `04_29篇剧情功能迁移表.md`：29篇的原作功能、迁移后篇名、地图、核心冲突和篇末结果。
6. `05_篇级迁移大纲_待生成.md`：按原作节奏完成的29篇详细剧情大纲第一版，文件名保留“待生成”作为后续精修入口。

## 维护规则

- 角色关系变化先改角色表，再改总表和篇级大纲。
- 地图扩展必须写明进入原因、区域秩序、资源、敌人、代价和出口。
- 所有迁移事件必须同时记录“原作剧情功能”和“新世界替代功能”。
- 角色、境界、地图和伏笔在前期、中期、后期分别进行连续性审计。
