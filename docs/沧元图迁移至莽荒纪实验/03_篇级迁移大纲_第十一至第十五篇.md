# 篇级迁移大纲：第十一至第十五篇

## 第十一篇 儿女初长成

### 1. 六州巡界与黑潮刺杀

林远凭暗星遁法在三十八息内赶到一千七百余里外的求援地点，黑潮妖王被迫把撤退时间压缩到二十息。黑潮会以金角虫毒刺杀林远夫妻，把毒物混入粥食和灯烟，林远依靠肉身神通切除中毒微粒才幸存，许宁因他打翻粥碗避过一劫。两人意识到妖族已经从正面战争转向家族刺杀，决定把儿女送入普通人家隐居。

### 2. 林安与林悠的十年成长

林远和许宁把林安、林悠化名为“林蒙”和“林悠”，送入青榆道院，由两名被收服的三重天妖王化作花伯、惠姨暗中保护。林安选择枪道，林悠选择剑道，四岁筑基、六岁先天、八岁紫府，十三岁同时触摸万象门槛。林远没有把高深传承直接灌入孩子体内，只把阴阳变化拆成最基础的枪法和剑法，让他们先经历普通人的成长。

### 3. 王琮案与神魔家族清洗

林安、林悠回家途中救下被云州王家旁支逼债的宁家姐弟，顺藤摸出王琮以家族势力强抢民女、转卖修行资源的内幕。王琮想把林悠送给江州萧家子弟，花伯出手制住众人，林安第一次杀人。王家不灭神魔王樊酬赶来，林远夫妻现身，以暗星领域将其镇压，并用元神秘术抹去他对儿女容貌的记忆。此案牵出江州城黑潮会情报点，林远下令不论牵涉哪一家神魔，都彻底清查。

### 4. 不死境与三大神通

林远十年间绘制《儿女欢》和七幅叩问本心之画，元神突破第四层，能够分化念头并把保命印记藏入儿女体内。他借洞天法珠本源修炼肉身，半年练成不死境，肉身微粒拥有独立生机。由此觉醒不灭神甲、天怒和扩大后的雷霆神眼，战力超过普通封侯神魔。秦岳又赠给他归元煞气和灰色护身符，林远开始成为玄元道庭真正的第一巡界使。

### 5. 地底探查与林安悟势

林远三个月深入地底，斩杀九千余名妖王和一头四重天大妖王，玄元道庭故意把战绩归到白钰王名下，保护他的身份。林远带林安、林悠看见妖王屠城和凡人在地底洞穴里苟活的真实世界，林安压抑的愤怒终于化为一枪，借天地之势击穿远处山峰，十三岁悟出枪势，被玄元道庭破格招入。林远送儿子上山，父子约定未来一起斩妖。

**篇末状态**：林远元神四层、不死境、封侯巅峰；林安悟枪势，进入玄元道庭；林悠剑道大成；黑潮会部分情报网被清除。

## 第十二篇 风云变色

### 1. 林安选轮回神魔体，三界筑城迁徙

林安进入玄元道庭后选择轮回神魔体，并选修古代祖师留下的轮回枪道，要求把五种意境融合。秦岳和白石下令三界弃守大部分府县，只保留大型城池，许宁以暗星领域和火焰道术帮助江州城扩建外城。大量凡人被迫迁徙，林远明白战争已经从救援局部变成整座三界的生存工程。

### 2. 归元煞气与斩潮蜕变

林远用近一年炼化归元煞气，寒煞和雷霆融合后，普通封王神魔沾上便会肉身冻结。他在地底斩杀一头四重天熊妖王，煞气把妖王分解成虚无，只留下帝君传承的熊形雕像。秦岳以元初道庭山主测试林远，林远用荡魂钟、天怒和归元煞气轰破山主神魔战体，证明自己已是三界顶尖封王，但杀敌手段仍需要更强的远程变化。

### 3. 黑潮最终决战爆发

黑潮异界召集六百余名四重天妖王和百万普通妖王，准备通过近两百处世界入口同时进入三界。妖王谢寒化身使者劝降林远夫妻，许诺人族可以保留一成疆域并改修黑潮法门，林远以“外族的承诺无法替代自己的家园”拒绝。韩九妖圣随后袭击广御关，六百余名妖王通过裂口进入三界，玄元道庭的卧底传回全部情报，三大人族道统同时启动沉睡封王、护道人和护法神兽三种底牌。

### 4. 林远连续三次救援

楚安城求援时，林远以荡魂钟冲击元神，五息内连续斩杀五名妖王；银湖关五名大日神魔战死，他故意示弱将六名妖王一锅端；东宁城被五重天青鳞妖王攻破，林远二十息赶到，先救下西海侯，再以心意刀侵入敌体、归元煞气减速、天怒雷爆，将青鳞妖王劈成十八截并活捉头颅。林远的救援速度成为三界唯一能够抵消黑潮突袭的力量。

### 5. 百年消耗战形成

第一波攻势中，玄元道庭战死十二名封侯神魔，黑潮妖王同样损失惨重。黑潮三帝君决定以百年消耗逼死沉睡封王和守城神魔，同时等待三界世界裂口增多，图谋古代祖师的遗留宝藏。林远回到地底探查日常，许宁被调往另一座城关镇守，夫妻只能靠书信见面。战争规模越来越大，林安和林悠都开始接近神魔门槛。

**篇末状态**：林远封王神魔，元神四层，归元煞气成形；三界妖王数量暴涨；林安修轮回枪道；林悠准备突破神魔。

## 第十三篇 叠界裂隙

### 1. 世界间隙出现

三界与黑潮异界在时空长河中第一次大范围碰触，形成“叠界裂隙”，其大小接近三界七成，只能容纳封王神魔。玄元道庭决定派叶沉、林远、贺川、叶清和许宁进入其中修炼一年，观察世界诞生时的时空断裂，并抢夺伴生奇物。林远知道自己若继续留在地底，只能慢慢积累战功，进入裂隙则可能找到突破道之境的机会。

### 2. 雷霆十五相与天地游龙刀

林远在裂隙中看到紫色雷霆撕开世界，连续九个月都没有突破刀道。第十个月，他放下战斗计划，画下十五幅雷霆图，从毁灭、虚空、电闪和游走等不同角度理解雷霆本质。画成后，他发现《心意刀》过于强调主观意志，转而修炼《天地游龙刀》，身法和刀法同时提升，一闪可跨越二十五里。林远第一次真正理解“天赋不是血脉，而是对本质的理解速度”。

### 3. 抢夺时空浮冰

世界断裂处喷出十余道星光，其中为首的是对道祖也有用的时空浮冰。林远带着贺川、叶清抢先抵达，黑潮五重天妖王乌沉和岳川城主随后赶到。叶沉以两拳击碎乌沉肉身，又以真武领域绞杀其真身；岳川城主的虚空神通也被彻底湮灭。林远没有抢走全部宝物，而是与叶沉按战功分配，展示出他从个人争夺者转向团队核心的变化。

### 4. 本源宝物争夺

十个月后，一座散发五彩紫气的大山从裂隙地底升起，本源宝物即将出世。毒龙老祖和血修罗先后出手，血修罗以血气秘术重创叶沉，林远以天怒救下他；叶沉以天劫剑和真武禁术击杀两大强敌。火凤、妖龙和牛妖趁乱夺宝，林远以天地游龙刀的身法先一步拦截本源宝光，最终保住宝物。许宁不在现场，却成为林远最想把宝物带回去的人。

### 5. 回庭与问心珠

林远等人提前回到玄元道庭，贺川获得剑道奇物，叶清改变水火兼修路线，林远则把雷霆十五相的感悟留存进画卷。他把贺川托付的冰莲花转交给周彦，帮助周彦稳定冰火元神。秦岳还得到一门火凤身法传承，准备送给许宁。三位尊者商议，战争正在消耗林远的修炼时间，或许必须动用道庭八大至宝之一的问心珠，帮助他补足道心。

**篇末状态**：林远封王神魔，刀法道之境巅峰，天地游龙身法大成；获得时空浮冰和本源宝物；贺川剑道突进；叠界裂隙仍在扩大。

## 第十四篇 东宁王

### 1. 创无尽刀与云雾龙蛇身法

回到三界后，林远每天六个时辰地底探查，剩余时间绘画和练刀。他借雷霆十五相创造《无尽刀》，以光芒相追求速度极致，又以天地游龙刀为基础创造《云雾龙蛇身法》，融入阴阳变化。贺川战死的消息传来后，林远绘制战友遗像，悲痛没有让他停下，反而让他的元神把“活着的人必须继续走”融入刀法。

### 2. 悟法域境

林远在深夜练刀时回忆所有战场，刀锋从雷光化为一条看不见的线，虚空中两里范围仿佛被折叠，敌人即使知道刀在哪里也无法躲开。他悟出法域境，雷霆、光芒、阴阳和分波四种意境第一次稳定结合。腊月，三位尊者为他护法，林远以清净神水压住心魔，把丹田暗星压缩成不可见的小点，凝聚无间真元和无间领域，正式突破封王神魔。

### 3. 百万妖王压境

黑潮妖王进入三界的数量达到六十万，并开始执行“自由狩猎”，每个凡人都成为妖王的功劳。玄元道庭建造剑皇城和多座超大型城关，调遣一千五百名大日神魔和三千妖仆巡守天下。三年内，十八名封侯神魔和五百名巡守神魔战死。林远境界更高，却第一次感到个人速度仍然无法覆盖整个三界。

### 4. 贺川战死与余烬妖圣

余烬妖圣恢复至洞天境后，选择在娑风城攻城时偷袭贺川。贺川激活道庭护身手环，仍然连抗七刀后战死；林远赶到时只能看见妖圣遁入地底。叶沉通过时空痕迹确认凶手是余烬，林远没有立刻追杀，而是把这笔血债记进《无尽刀》的下一次突破里。周彦收到贺川留下的万剑传承，决心完成朋友未走完的路。

### 5. 子女与许宁的调任

林安十六岁练成轮回神魔体，闯过生死关并进入星河遗府接受轮回试炼；林悠也不愿再等待，主动闯生死关成神魔。周彦突破封侯，得到冰莲花帮助后完成冰火元神融合。许宁连续施展火凤涅槃守城，寿元损耗超过三十五年，林远写信请求秦岳将她调往江州城，夫妻再次结束长期分居。

**篇末状态**：林远封王神魔无间境；法域境刀法；贺川战死；林安获得轮回传承；许宁封侯巅峰且寿元受损；余烬妖圣成为核心仇敌。

## 第十五篇 血刃盘

### 1. 祖师殿挑选至宝

林远突破封王后，叶沉以元神分身测试他，指出无尽刀速度太极端，变化不足。三位尊者带他进入祖师殿，从异宝、源宝、造化宝物和劫境宝物中任选两件。林远选择劫境护法宝物“血刃盘”，能够分化十八柄血刃，兼顾飞遁和护身；又选择源宝“青云天”，可以借玄元道庭本源形成青色领域和雷霆护罩。两件宝物让他的战斗方式从单人刺杀转为大范围猎杀。

### 2. 血刃盘炼化与地底屠杀

林远用元神分身渗透血刃盘，两个多月后完成本命炼化，速度提升到一闪一百二十里。血刃盘符纹中包含光芒、九天、阴阳和游龙四种大道线索，像一位不会说话的传承导师。林远戴上“幻影之面”，伪装成古老的十三剑煞神魔，开始在三大王朝地底屠戮妖王，每天斩杀八百头，黑潮高层只知道有一个神秘强者，却无法确认身份。

### 3. 渝商城救援

渝商城遭五重天摩弋妖王偷袭，宁雪侯重伤濒死。林远脚踏血刃盘，三千里路程两息赶到，以血刃从百里外斩杀摩弋，故意让幸存者认为出手者是十三剑煞神魔。玄元道庭三位尊者通过虚空波纹观察战斗，确认林远已经拥有接近帝君的远攻能力。黑潮会九成认定神秘强者是某位沉睡古神魔，继续把大量力量用于追查身份。

### 4. 林岳加入巡守

林岳借林远的功劳突破大日神魔，主动报名成为巡守神魔。林远为父亲换取储物袋、血影甲和一件保命宝物，林岳却拒绝留在江州城，认为修行者终究要在守护众生的地方死去。林岳带两名妖仆出征，苏晚在月河洞天读到信后只能远远思念。父亲真正走上战场，使林远第一次体会到“守护家人”和“尊重家人的选择”之间的矛盾。

### 5. 三绝阵与余烬之死

余烬妖圣、裴隐妖圣和长游妖王在大周地底布置三绝阵，隔绝天地、时空和因果。林远探查时陷入阵中，青云天和传讯令牌全部失效，只能依靠云雾龙蛇身法在深层虚空中躲避冥河刀、幻术和毁灭光线。血刃盘斩杀长游与裴隐分身，余烬分化二十八道流光逃亡。秦岳以裂天剑遁赶到，最终识破余烬夺舍小妖王的真身，将其斩杀，成为三界内第一位陨落的妖圣。

**篇末状态**：林远封王神魔无间境，元神四层，拥有血刃盘和青云天；余烬妖圣死亡；裴隐、韩九和千秋妖圣继续潜伏；林岳成为巡守神魔；黑潮帝君开始策划咒杀林远。
