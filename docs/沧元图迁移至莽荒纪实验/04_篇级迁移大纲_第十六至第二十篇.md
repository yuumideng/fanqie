# 篇级迁移大纲：第十六至第二十篇

## 第十六篇 滴血境

### 1. 扫清三界与两大道统谈判

林远先扫清大周地底妖王，再向两界道宗和月河洞天提出帮助清除各自境内妖王，交换条件是让苏晚回到林岳身边。两大道统同意，以一件阴阳镜和一座化龙池作为报酬。林远转战大越和黑沙王朝，斩妖刀吞吸数十万妖王怨气后变得漆黑，刀中出现陌生心灵低语。黑潮妖王被迫逃往海洋和无人荒地，三界陆地短暂恢复平静。

### 2. 许宁成封王与林远元神五层

许宁在练箭时突破元神三层，随后以火凤神魔体突破封王。林远则以画道和战争记忆推动元神蜕变，元神达到第五层，能够凝聚大量分身。两人共同完成一幅《归家图》，却暂时不能真正让苏晚回家，因为黑潮必然把这个消息视为神秘强者的弱点。

### 3. 沧海遗府的线索

林远在海底追杀妖王时，发现一处残破的沧海派遗迹。遗迹属于三界古老道统沧海宗分裂出的支脉，内部有群星楼、心海殿和战神塔三座核心建筑。林远先进入心海殿，面对心灵幻境和自身杀意；又进入战神塔，接受一位位古代神魔留下的战斗烙印。他的元神分身在考验中连续崩溃，却始终没有放弃。

### 4. 千秋妖圣与因果血咒

黑潮三帝君强迫千秋妖圣在三界三千名妖王身上布置因果血咒，通过统计谁杀死这些诱饵，确认神秘强者身份。林远连续斩杀的妖王中有五百余名来自血咒名单，千秋终于确认“东宁侯林远”就是地底猎杀者。赤星帝君隔着世界以血字书写林远姓名，九日咒杀同时侵入肉身和元神，林远靠元神星辰法门和滴血境肉身硬抗，重伤但没有死亡，赤星帝君反而遭受反噬。

### 5. 沧海双考与求援

林远通过心海殿和战神塔前五名的双重考验，得到沧海宗全部宝藏，但拒绝独吞，准备把传承交给玄元道庭。就在他准备传讯时，沧海遗府中的护法神透露黑潮正在寻找这里。林远以最低层级的求援令传出消息，三大尊者立刻派出元神分身赶来。篇末，林远已经成为三界最受关注的封王神魔之一。

**篇末状态**：林远封王神魔，滴血境肉身，元神五层；许宁封王；沧海遗府被发现；千秋妖圣确认林远身份；因果咒杀失败。

## 第十七篇 名震三界

### 1. 沧海传承归玄元道庭

秦岳亲自接收沧海宗三大镇宗宝物，玄元道庭重新聚齐十二件镇宗重宝。林远因功劳超过历代弟子，被破例封为第四掌令者，向天地大殿发誓守护道统和三界。白石向他解释沧海宗与玄元道庭的分裂历史：古代祖师故意把内部争论分成两脉，避免所有传承同时毁灭。林远由弟子转成真正的道统掌权者。

### 2. 群星楼绝学与两座古塔排名

林远进入群星楼，翻阅雷霆一脉的尊者级、帝君级和劫境绝学，重点选择《雷霆界》和《三世刀》。战神塔中，他以“斩潮人”名义排名第五；心海殿中排名第一，超过历代许多帝君种子。三位尊者决定隐藏他的真实排名，避免黑潮提前不惜代价围杀。

### 3. 千秋咒杀失败后的刺杀

韩九妖圣携帝君赐下的暗界之眼降临江州城，暗红牢狱把十里天地变成自己的小世界。石牛异兽和许宁的火凤箭挡住第一掌，林远以血刃和魔锥连续穿透韩九元神。韩九缩小牢狱准备一拳杀死许宁，林远主动挡下大半威力，许宁在火凤涅槃中一箭贯穿韩九胸口。韩九元神重创，逃出三界膜壁，秦岳一剑追杀却被域外的金羽帝挡下。

### 4. 夫妻双封王，苏晚回家

玄元道庭向三界公开林远斩杀百万妖王、越阶战妖圣的战绩，林远和许宁正式被封为东宁王、宁月王。林远终于向月河洞天提出交换条件：允许苏晚回到大周王朝与林岳生活。月河洞天考虑林远未来可能成为帝君，答应解除禁令。五十多年后，林岳和苏晚在道庭山脚重逢，林远第一次喊出“娘”。

### 5. 武阳侯伏法与天下清剿

淳于牧之子送来父亲遗书，揭露武阳侯当年陷害林岳并向黑潮透露情报。林远不亲自处刑，而是把证据交给月河洞天，武阳侯最终被查出勾结妖族并处死。林远继续清扫三界，普通妖王被雷磁领域直接杀死，强者则被收入妖仆体系。林安的轮回试炼秘密也被揭开，他已经成为古代祖师的真传候选者。

**篇末状态**：林远、许宁双封王；林远为玄元道庭掌令者；苏晚回到林家；韩九逃入域外；天下妖王基本被清除。

## 第十八篇 元神六层

### 1. 群星楼开放与叠界裂隙追杀

林远把群星楼、战神塔和心海殿的部分权限开放给玄元道庭，三界封王神魔开始集体提升。黑潮五重天妖王潜伏叠界裂隙多年，三位尊者决定主动进攻，安排林远与护道人白石同行。林远第一次以元神星辰波动大范围攻击，一击抹去九名五重天妖王的意识，迫使黑潮重新评估他的战力。

### 2. 风之本源宝物与身法突破

牵机圣主率领妖王队伍救援，林远以流沙神通减慢时间、以天怒斩杀白原和裂岳妖王，再由白石用魔锥重创牵机圣主。数年后风之本源宝物出世，林远进入狂风漩涡，双腿被绞碎后靠滴血境重生，夺得宝物。黑潮派金雀君主、牵机圣主和玄蚀老祖总攻，林远借血刃盘符纹把云雾龙蛇身法推入洞天境，潜入深层虚空斩杀十八名黑河护卫，破掉黑河大阵。

### 3. 叶沉以命运草人斩玄重妖圣

玄重妖圣夺舍潜入叠界裂隙，黑潮队伍用虚空挪移符瞬间汇合。赤龙妖圣被秦岳尊者斩杀，玄重藏进玄蚀老祖洞天，所有普通攻击都无法触及。叶沉以命运草人拜祭三日，燃烧寿元和元神，因果力量越过小型洞天直接斩杀玄重妖圣。叶沉死亡，黑潮接引五重天妖王进入三界的计划彻底失败。

### 4. 顾苍元神分裂

三界两座城池连续被神秘刀法屠杀百万人，林远三息赶到后认出杀招属于顾苍的春秋劫。凶手被擒后气息和顾苍完全相同，秦岳用元神秘术唤醒主意识，发现顾苍修炼黑潮冥想法后分裂出邪恶意识。玄元道庭将他改造成寒冰生命，放逐叠界裂隙三百年赎罪；他的儿子周彦收到遗书，第一次承认父亲的道路确实走歪。

### 5. 林远元神六层与人族新时代

林远完成第二次雷霆十五相，元神突破第六层，云雾龙蛇身法达到洞天境，魔锥也以三成元神本源炼成。黑潮妖圣接连陨落，三界从被动防守进入只需镇守世界入口的新时代。周彦在叠界裂隙中继续赎罪，林远则把叶沉留下的空位视为新的责任。

**篇末状态**：林远封王神魔，滴血境，元神六层，云雾龙蛇身法洞天境；叶沉牺牲；玄重、赤龙、余烬死亡；顾苍被放逐赎罪。

## 第十九篇 尊者

### 1. 神魔家族腐败与监察部

三界太平近四十年，神魔家族后代开始借祖辈名望压迫凡人。林远赴曲云城为叶清庆贺封王，发现地网巡查葛成暗中抓人、贩卖和虐杀百姓，还借林家名号遮掩。林远当场擒下城主唐岳，命令三大人族道统建立监察部，彻查神魔家族犯罪。平民第一次敢于指证修行者，林远也意识到守护制度和守护战场同样重要。

### 2. 风雪关与许宁燃烧寿元

风雪关世界入口突然扩张，五名五重天妖王冲入。许宁施展火凤涅槃斩杀一名妖王，其余退走。黑潮三帝君带毒龙老祖亲临，毒龙化为百里黑水，准备淹没风雪关一千多万人。许宁燃烧两百余年寿元，以火凤洞天护住近两百里人族，终于悟出不死神火，一箭钉死毒龙老祖。她从盛年变成白发，林远却没有阻止她，因为他知道那是她自己的选择。

### 3. 一瞬千年

许宁寿元只剩五十余年，秦岳建议她进入一瞬千年殿沉睡，等待林远未来成为道君或帝君后寻找延寿之法。夫妻二人用最后一年走遍曾经生活过的地方，重新看北河关、江州城、顾山府和林家祖宅。一年后，许宁沉睡，林远独自回到空荡的风雪关，孤独和不甘彻底爆发。

### 4. 极限绝学无尽刀与元神七层

林远不再压抑思念，把两人从少年到成亲后的全部经历画成十五丈长卷《执手》。月下醉舞时，他劈出一刀，刀锋从时间和空间缝隙中出现，敌人无法看见也无法预测，正式悟出三界第一门由自己创造的极限绝学“无尽刀”。随后元神自然突破七层，分化出九尊可独立施展无尽刀的分身，获得以一人镇守九座城关的能力。

### 5. 混洞境与域外出发

林远把无间境之源重新压缩成黑暗混洞，吞吸一年多天地之力，形成神魔炼体与元神都未有过的混洞境。混洞领域能够排斥天地规则，肉身粒子各自化为微型黑洞，寿元增加到五千年。三位尊者要求他进入域外修行，林远把一尊真身留在天地大殿镇守三界，另一尊撕开世界裂缝冲入无尽混沌，成为八百年来第一个主动出域的人族神魔。

**篇末状态**：林远混洞境、元神七层、极限绝学无尽刀；许宁一瞬千年沉睡；林远真身一分为二，一尊镇守三界，一尊进入域外。

## 第二十篇 域外新人

### 1. 初入域外与方行追杀

域外元力足以摧毁封王神魔，只有尊者层次才能长期遨游。林远用幻影之面伪装造化尊者，借放逐牢狱逃离金羽帝追杀，却被赤阳界尊者方行强迫探路。方行不信他的来历，双方在时空乱流中交手。林远以混洞领域排斥空间囚禁，血刃配合无尽刀远攻，最后用元神七层魔锥粉碎方行元神；方行靠替死符复生，仍被林远追杀至真身陨落。

### 2. 庞山遗府

林远从古青尊者口中得知五劫境大能庞山的洞府，利用白星矿石持续轰击虚空囚笼三个多月，终于耗尽阵法能量。庞山留下的幻境意念要求林远收一位庞山界尊者为徒，林远为尽快结束三界战争接受条件。遗府中有七劫境葫芦、六劫境战甲和大锤、八首吞星蛇尸体、黑暗孔雀血肉和空间塔，林远由此得到进入域外交易圈的第一笔资本。

### 3. 黑龙星交易

林远在黑龙星参悟黑暗孔雀血肉五年，发现其中既有极限速度规则，又有另一种可以与速度融合的规则。他购得雷霆星辰子、囚魔牢狱和画册《无我无相剑》，并以庞山遗物换取时间洞府和原初之石。黑龙老祖寿元将尽，黑魔殿正在盯上整个黑龙星，林远不愿卷入争斗，却开始把这里视为域外真正的修行起点。

### 4. 原初之石与肉身蜕变

原初之石无法被七劫境以下强者损伤，却主动引起林远丹田混洞的吞噬本能。林远观察七天后将其吞入混洞，肉身每一粒微粒同时蜕变，真元数量增加十倍，混洞领域威力提升三倍，纯粹肉身力量接近帝君后期。林远发现域外真身因此强大，留在三界的真身无法同步获得这份提升，两个真身开始出现发展差异。

### 5. 三界真身俘虏妖王大军

黑潮两名夺舍妖圣从海域边缘打通连接点，准备把一百九十三名五重天妖王送入三界。林远没有提前阻止，而是分化八尊元神分身守住八方，等妖王全部进入后以元神星辰波动一击使其失去意识，连两名夺舍妖圣也被活捉。三界各方震动，金羽帝判断林远至少已经达到元神七层，决定闭关等待“妖圣通道”出现。

**篇末状态**：林远域外真身混洞境后期，肉身蜕变；三界真身元神七层，活捉一百九十三名五重天妖王；黑魔殿和妖圣通道成为后续主线。
