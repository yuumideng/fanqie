# 《沧元图》剧情迁移至《莽荒纪》世界的实验设定

> 版本：v1.0
>
> 说明：本实验保留《沧元图》全书 29 集的主要剧情顺序、关键结果和因果推进，只对人物、势力、世界机制、修炼方法和无法直接对应的事件做最小必要本土化处理。本文件是后续篇级大纲和迁移表的共同设定基准。

> 当前正文试读分支说明：`21_前五章正文统一稿.md` 已合并第一至第五章，作为独立化开局实验的唯一正文依据。开篇节奏按“第一章危机立人设并回家—第二章伤后休养读书—第三章完成世界观与体系—第四章道院测力—第五章作出修炼道路选择”执行。第一章只保留“水闸危机—林远出场立人设—回家交代家庭与城防压力”的闭合结构，不把血针、阵纹改动、蓑衣人或追查后续接入这次危机；许宁只承担情感锚点和主角升级触发功能，不承担战斗配合；阵务官不在第一章建立人物线。

> 关联档案：角色一一对应和关系硬约束见 `09_角色对照表_原作至新小说.md`；三界之外的区域层级、压缩原因和后续扩展路线见 `10_地图迁移审计与扩展方案.md`。

## 一、迁移原则

1. 全书宏观骨架按原作每一集对应新小说一篇，共 29 篇；需要进行完整迁移时，必须在篇级骨架下继续建立原作章节的一一对应稿，不得把篇级稿误当成逐章稿。前五篇的逐章修订稿见 `13_逐章迁移大纲_第一至第五篇_修订版.md`。
2. 每篇保留原作主要剧情结果，原则上保留“谁推动事件、冲突如何升级、主角如何解决、篇末留下什么后果”。
3. 原人物全部替换为新人物。对照表可以出现原作人物作为追踪标识，但新小说大纲不使用原姓名。
4. 原作的妖族、人族、元初山、黑沙洞天等名词全部改造为适合三界和无尽混沌的设定。
5. 《莽荒纪》原有力量体系优先；原作中没有直接对应的早期阶段、特殊传承或宇宙层机制，增加桥接设定。
6. 每个剧情点写成详细段落，至少交代事件、人物关系、冲突、迁移方式和结果。
7. 原作角色与新角色必须通过角色对照表建立唯一主映射；未命名的功能位必须标记为待补写，不能在不同篇章中临时改换对应人物。
8. “域外”只是总称，不等于完整地图。若继续扩写《莽荒纪》规模，必须先按地图扩展方案拆分区域，再分配剧情功能。

### 2.1 关系硬约束

- **林远与许宁**：幼年相识的重要情感关系；许宁不是战场搭档，不与林远比较修为。前期只承担温柔克制的生活照料和情感锚定，不能用她的台词替林远判断、悟道或推进主线。
- **林远与苏萍**：当前正文不建立关系。婚约、退婚和苏萍个人线属于旧迁移档案，不得写回本次正文试读。
- **许宁与许河**：父女；许河同时是林岳的生死兄弟。
- **周彦与顾苍**：父子；顾苍的元神分裂和赎罪线必须通过周彦承接，不能改写为许宁的家族线。
- **名称统一**：同一角色统一使用“周彦”“叶清”“青羽馆”，不再使用“周烈”“阮童”“白鸟馆”等旧称。

### 2.2 独立化正文试读分支覆盖

以下规则仅适用于当前第一至第五章正文试读，不覆盖旧迁移大纲：

- **林远与许宁**：许宁是林远幼年相识的情感锚点，前五章只负责送药、照料和少量生活互动，不参与战斗、推理或修炼指导；她的出场必须有明确的生活功能，没有必要时不强行出现。
- **阵务官**：不命名、不建立人物线；第一章不安排其出场，后续若需要阵务信息，由卷宗、魏安或无名修士在独立事件中承担。
- **林岳**：只有先天境修为，能提供有限经验、训练条件和家传笔记；不能替林远确认超出当前阶段的道路，更不能用隐藏实力解决危机。
- **敌方主线**：血色骨针、镇魔阵破坏、黑潮裂缝和青河府内应属于后续独立事件的线索，不得倒灌回第一章的水闸危机；前五章若启用，必须先有新的触发事件和因果铺垫。

## 四、力量体系迁移

### 4.1 前期桥接

原作前期的洗髓、脱胎、无漏、凝丹和神魔体，不直接照搬名称，改为莽荒体系下的凡俗修行和神魔炼体桥接：

> 后天 → 先天 → 紫府 → 万象 → 元神道人/地仙 → 天仙 → 纯阳真仙 → 天神/真神 → 世界境 → 道君 → 帝君/合道

其中，前期会允许林家和道院使用“炼体九阶”“神魔体九炼”等地方性称呼，作为从凡俗肉身过渡到神魔炼体的训练术语；正式大境界仍以莽荒体系为准。

### 4.2 林远的多路线

- **表面路线：长枪与神魔炼体。** 林远先以枪术成名，枪法看似偏守，实际通过枪杆卸力、枪锋反击和步法封位，在近身战中形成“越打越稳、越守越强”的特点；后修炼厚土神魔体，再进入金刚、神通、不死、滴血等肉身路线。
- **隐藏路线：元神与心力。** 林远早期因绘画和观察众生，提前凝聚元神；中期以心力承载枪意和元神秘术，能够看穿敌人的力量落点，形成同级难以判断的第二战力。
- **第三路线：土行枪道。** 长枪、防御和土行之意不是三种互不相干的能力，而是逐步从技艺、枪势、土之真意、领域走向能够镇压空间和承载世界的个人道路。
- **后期个人道路：以心力统合肉身、元神、土行和时空。** 这条道路不是外置金手指，所有能力都由林远在比赛、战争、绘画、失去和传承中逐步获得；土行负责承载根基，枪道负责攻守转换，心力负责让两者真正合一。

### 4.3 关键境界对应

| 原作功能阶段 | 新小说境界处理 | 剧情表现 |
|---|---|---|
| 少年修炼、悟秘技 | 先天至紫府，枪术合一 | 林远把一套基础枪法练成攻守一体的个人技艺。 |
| 枪势、心魂觉醒 | 万象至元神道人，初触心力 | 主角开始感知战场、借助地势承压，并拥有隐蔽的元神优势。 |
| 神魔体、丹云、大日 | 天仙至纯阳真仙，神魔炼体成长 | 肉身、真元、元神同步增长，厚土神体让他具备战场级防守和反击能力。 |
| 道之境、法域境、封侯封王 | 天神、真神、道祖层次 | 个人绝学和领域开始影响大范围战争。 |

| 劫境、帝君、元神八劫 | 道君后期、帝君、合道前后 | 主角从三界强者进入时空长河顶层，最终面对自身心劫。 |

## 五、篇级迁移统一格式

每篇固定包含：

1. 篇名与承接状态；
2. 3—7 个详细剧情点；
3. 主角境界和多路线变化；
4. 新增或改变的人物关系；
5. 篇末保留的主要结果与悬念。

详细对照表另列：原剧情节点、原剧情功能、新人物/关系、本土化事件、莽荒力量对应、剧情结果和新增伏笔。
