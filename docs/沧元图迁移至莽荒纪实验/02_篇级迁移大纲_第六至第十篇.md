# 篇级迁移大纲：第六至第十篇

## 第六篇 英雄征四方

### 1. 赤血崖送行与刀魂

九年间，玄元道庭一批批神魔下山，赤血崖上的名字越来越多。林远在万雷峰修炼，终于把刀意凝成刀魂，明白刀不只是武器，而是自己看待生死和世界的方式。他以刀魂闯九玄洞，斩杀普通妖王，却被一头擅长不死秘法的山妖挡住。秦岳这才允许他完整接受《心意刀》和《天地游龙刀》的传承，林远在三个月内悟出心意刀第二式“虚空折返”。

### 2. 突破大日神魔与九玄洞

许宁其实已经触摸到神魔元神的门槛，却一直等林远同行。林远以刀魂引导金丹坍缩，在丹田中凝聚一轮雷霆大日，成为大日神魔；许宁随后也完成火凤神魔体蜕变。林远再次闯九玄洞，以虎啸刀撕开山妖外壳，以龙吟刀连续贯穿其真身，最后用心意刀炸碎命核，成功通过考验。两人的境界和配合正式达到可以下山独当一面的程度。

### 3. 元神成长与斩妖刀

秦岳传下元神九层体系，林远已经达到元神二层，可以夜游、凝聚元神兵器和扩大领域。他在神兵窟中以刀魂压服一柄吸收血肉怨气的暗红邪刀，将其命名为“斩潮”。斩潮会反噬主人，却能把敌人死亡后的煞气转成刀威，恰好对应林远“越战越强”的路线。林远又绘成《英雄征四方》，把战死和仍在战斗的同门都画入其中，元神领域扩大到二十丈。

### 4. 星河遗府与肉身传承

秦岳和白石尊者为林远开启玄元道庭深处的星河遗府。林远在十二根通天柱之间经历红雾、黑影和心神迷失，最终获得一枚星空晶石以及古代混沌神魔的肉身传承：金刚、神通、不死、滴血、入圣、神话六重。这个传承与他原本的雷霆神魔体并不冲突，而是给肉身提供更精细的粒子修炼方法。林远决定隐藏星河遗府的全部收获，只向许宁透露一部分。

### 5. 下山前往北河关

林远和许宁在赤血崖留下自己的名字，随南云真人赶往北河关。秦岳告诉林远，北河关不是历练场，而是三界最容易死人的战场；如果想真正保护林家和青河府，就必须先学会承担一座关城的生死。林远握住斩潮，和许宁并肩踏入混沌裂口。

**篇末状态**：林远大日神魔，元神二层，刀魂大成；开始修炼星河肉身传承；获得斩潮；许宁成为凤凰神魔；二人抵达北河关。

## 第七篇 北河关副将

### 1. 初到北河关

北河关守将章虎把林远任为副将，同时授予他“巡界使”身份，负责十八府之间的紧急救援。林远认识石修、穆青、俞赤琰等九名副将，第一次看到同门之外的军队体系。第一次妖族攻城时，林远建议在关城外蓄水，以雷霆刀道把整片战场变成雷池。他以龙吟刀瞬杀五名妖王，再以雷霆神通清空三万凡俗妖兵，北河关第一次真正记住了他的名字。

### 2. 巡界救援与金刚身

林远在苍山府、高岚县和鱼禅县连续救援，每次都故意隐藏身份，只以“路过的刀客”出现，防止黑潮一方推断出三界巡界网络。战斗之余，他按照星河遗府传承微观观察肉身，把每一粒神魔血肉都炼成完整循环，六个月后练成金刚身。金刚身让他不施展禁术也比下山时强一倍，斩潮和雷霆刀法终于有了足够稳固的肉身承载。

### 3. 狮妖王针对与战场突破

黑潮异族派出拥有吞雷神通的狮妖王，专门克制林远的雷霆路线。第二次大战中，狮妖王借地脉反吸雷电，迫使林远放弃远程优势。他以元神融入真元，施展神魔禁术，先用心力扰乱狮妖王识海，再以斩潮近身切断其妖丹。狮妖王和五名精英妖王同时陨落，林远的刀魂在极限杀意中迈入圆满，北河关将他称为“第一副将”。

### 4. 成亲与母亲伏笔

林远和许宁在北河关成亲，林岳、许河等亲人穿过战场赶来。成亲当日，一个青衣蒙面的女子在远处酒楼看着林远，却不敢现身，只能在天黑前离开。林岳独自饮酒，认出那是失踪多年的苏晚，却选择继续隐瞒，因为苏晚一旦被月河洞天发现，林家所有人都会遭到牵连。林远开始怀疑母亲或许没有死。

### 5. 三界局势恶化

白石尊者传来消息：黑潮异族已经找到更多世界入口，三界不能继续守住所有小型关城。玄元道庭决定放弃部分中小关隘，把异族放进三界腹地，再用巡界使和地网逐个猎杀。林远刚成亲就接到新的调令，北河关的胜利并没有带来和平，反而成为更大灾难的前奏。

**篇末状态**：林远大日神魔，肉身金刚境，元神二层，刀魂圆满；许宁为道侣；苏晚仍生存但身份成谜；黑潮异族准备大举进入三界。

## 第八篇 暗流

### 1. 放弃小关与三界大迁移

两界道宗因大日神魔数量锐减，提出放弃小型关城、启动大迁移的战略。三大人族道统经过争论后通过计划，开始把府县百姓迁往大型城池，并建立由凡俗军队、坞堡、城池和巡界使组成的地网。林远和许宁被调往江州城，负责清查黑潮会潜伏者。无数百姓被迫离开祖地，林远第一次看到“守护世界”意味着也要做出残酷取舍。

### 2. 江州城镇守与黑水宫主

江州城由张烈式的领域强者张烈和近战强者杨川共同镇守，林远负责元神领域巡查。三个月内，他抓住十七名黑潮会弟子，顺藤摸出黑潮会主亲自下令的情报。黑潮会黑水宫主率百余名妖王攻城，林远在南城斩杀多名妖王，却在东城被黑水宫主偷袭重伤。张烈以领域困敌，杨川正面压制，林远以速度绕后，三人合力越阶斩杀黑水宫主。

### 3. 长丰府陷阱

林远和张闻奉命支援长丰府，中了庄孚大妖王以蛇妖领域铺设的陷阱。庄孚的毒桩能够穿透神魔护体，林远只能用心力感知毒桩轨迹，带着张闻从一里半的缝隙逃走。庄孚转而杀死其他救援神魔后遁入地底，林远第一次意识到，真正的高阶妖王不会和他正面决战，而会把整片战争变成猎场。

### 4. 获封东宁伯

回玄元道庭后，秦岳把《雷霆神魔体》下篇完整传给林远。林远在战斗中突破刀魂巅峰，并把第二重雷电神纹刻入肉身，雷霆速度和爆发再次提升。他因斩杀黑水宫主获得大量道庭功劳，被封为东宁伯。江州城的地网正式由林远和许宁共同负责，夫妻二人隐居顾山府，开始接受黑潮大军进入三界后的新战争模式。

### 5. 同门群像变化

张烈因强行施展神魔禁术只剩一年寿元，决定独自游历；钱钰丹田受损，改修纯粹炼体；周彦为了压制体内异域血脉，修炼冰火两种元神，性情越来越冷；贺川卡在元神门槛；宁川在大迁移中战死。林远和许宁重逢后明白，战争正在把同一批天才塑造成完全不同的人。

**篇末状态**：林远大日神魔，刀魂巅峰，第二重雷电神纹；许宁与其共同担任巡界使；三界完成大迁移；庄孚大妖王成为长期敌人。

## 第九篇 妖乱三界

### 1. 妖王群体进入人间

黑潮异界派出白狐妖王和青玉妖王等三重天妖王，分头潜入顾山府，同时袭击府城、县城和坞堡。林远以元神领域识破白狐的魅惑神通，一刀将其斩杀，青玉借江河领域逃走。玄元道庭随即调整防线，退出普通不灭神魔，把地网交给凡俗军队和坞堡，以四名大日神魔组成小队进行救援。

### 2. 夫妻巡界与《长路图》

林远和许宁表面隐居画画，接到求援后立即跨府赶路。许宁在高空以火凤箭覆盖战场，林远在地面以雷霆快刀逐个斩杀妖王。夫妻二人救下回头保护凡人的钱莫式神魔，也亲眼看到无数普通人死在撤离途中。林远把北河关、江州城、地网崩溃和同伴背叛全部画进《长路图》，将这条路定义为通往胜利的血路。

### 3. 元神三层与神通境

林远为怀孕的许宁绘画时，元神蜕变至第三层，可以夜游、分化元神兵器。他凝练出“诛魂刺”，专门攻击妖王元神，并用三百枚赤血神丹修炼肉身神通。神通境使他把元神念头刻入每一粒肉身微粒，肉身从金刚境进阶为神通境，开始具备真正的封侯级战力。

### 4. 斩杀伏角大妖王

伏角大妖王在安平县设下七妖王诱饵，准备等一个封侯级天才上钩，却等来了林远夫妻。伏角的黑枪、斩敌金光和蚀灭气同时爆发，林远以五十丈元神领域提前发现杀招，先用诛魂刺重创其元神，再用虎啸、龙吟和斩潮连续贯穿肉身，越阶斩杀四重天妖王。斩潮吞吸伏角血气后变成暗紫色，第一次显出可能反噬林远心力的征兆。

### 5. 双胞胎出生

秦岳以一件凤凰奇宝换取林远战利品，帮助许宁纯化火凤血脉。九月，许宁诞下一子一女，林远看着新生的林安和林悠，立下保护他们的誓言。与此同时，四重天妖王伏击的规模继续扩大，林远明白孩子的出生不是战争结束，而是他必须更快变强的理由。

**篇末状态**：林远元神三层、神通境肉身、封侯级战力；许宁怀孕到产子并强化火凤血脉；黑潮异族开始针对林远夫妻；林安、林悠出生。

## 第十篇 东宁侯

### 1. 雷霆神眼与寂灭寒煞

林远把神通境修炼到完整状态，元神意识烙印肉身每一粒微粒，眉心生出雷霆神眼，形成覆盖五里的雷磁领域，能够探查地底。与此同时，他炼成寂灭寒煞，寒煞可以冻结大日神魔和三重天妖王，让他的雷霆快刀获得控制战场的能力。力量体系从“单点斩杀”变成“领域、感知和近战同步压制”。

### 2. 林岳被诬陷，苏晚身世揭开

月河洞天的赵侯嫉恨苏晚当年选择林岳，指使幻术修行者篡改林岳记忆，诬陷他勾结黑潮会。林远强闯吴州城地牢，把父亲带回玄元道庭。秦岳和白石用元神秘术查明记忆被改，幕后赵侯被月河洞天责罚。林岳终于承认苏晚没有死，她是月河洞天的太阴圣女，因宗门禁令只能暗中观看林远成长。林远新的目标从守护家族变成让一家人重新团聚。

### 3. 黑潮大规模入侵

三百余名三重天妖王通过世界入口进入三界，由韩九妖圣统领，分别潜入三大王朝。坞堡被迫搬迁，县城逐渐衰败，凡人开始依靠大型城池求生。玄元道庭诞生新的封侯神魔，但也有十六名顶尖神魔战死。林远夫妻接到镇酉县求援，发现黑岩妖王用龙水域宝物困住他们。

### 4. 龙水域临阵突破

许宁施展火凤涅槃，短时间达到封侯级战力，却燃烧十八年寿元。林远被黑岩妖王重锤击伤，在凤凰火焰抵御龙水域的瞬间，看清心意刀中阴阳变化的本质，悟出道之境的第一层。为了救许宁，他强行把无间真元和暗星领域融入丹田，突破到暗星境，速度一跃超过历代雷霆神魔。黑岩妖王被吕越王擒下，供出韩九妖圣潜伏和妖王分布。

### 5. 夫妻双封侯，迁居江州城

许宁因火凤涅槃带来的元神蜕变，也突破暗星境。林远被封为东宁侯，许宁被封为宁月侯，六州一百余府的巡界救援交给林远，江州城地网交给许宁。林家举族迁入江州城，新的林家大型宅邸改为“东宁林府”。林远看着家人，却知道韩九妖圣已经把三界当成一座即将引爆的战场。

**篇末状态**：林远暗星境，刀道入道，半步封侯顶尖；许宁暗星境；夫妻双封侯；苏晚尚在月河洞天；林安、林悠进入隐藏成长阶段；三界进入全面战争。
