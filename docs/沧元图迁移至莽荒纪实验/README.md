# 《沧元图》→《莽荒纪》剧情迁移实验

本目录保存一次完整的篇级剧情迁移实验：保留《沧元图》全书 29 集的主要剧情顺序和结果，全部替换人物姓名，并将世界观、势力和力量机制本土化到三界、无尽混沌、神魔炼体、元神、心力、世界境、道君和劫境体系中。

## 产物

1. `00_迁移规则与新设定总表.md`：固定迁移原则、人物、势力、力量和统一格式。
2. `09_角色对照表_原作至新小说.md`：原作角色与新小说角色的一一对应、关系硬约束和待补映射。
3. `10_地图迁移审计与扩展方案.md`：说明三界篇压缩的原因，并给出《莽荒纪》式外部地图扩展路线。
4. `11_迁移实验复盘与通用防错规则.md`：总结迁移问题、修正办法和正文前置检查流程。
5. `13_逐章迁移大纲_第一至第五篇_修订版.md`：前五篇116章的章节摘要。
6. `14_逐章剧情覆盖审计_第一至第五篇.md`：前五篇116章的关键节点覆盖和扩写基准。
7. `15_正文文风校准与创作流程.md`：正文写作的叙事风格、场景推进和验收标准。
8. `21_前五章正文统一稿.md`：第一至第五章的连续正文，统一执行人物心理、配角反应、生活化对白和战斗决策标准。
9. `22_前五章篇幅与连贯性审计.md`：记录原作对照方法、篇幅复核、世界观承托和本轮正文修订结果。
10. `23_前五章爽点与主角成长审计.md`：对照原作前五章，审计新文爽点、主角成长和女性角色功能。
11. `25_原文前五章人物描写统计.md`：统计原文前五章的主角心理、配角表情、配角行为和配角心理，并作为正文人物描写校准基线。
12. `26_第一卷篇级大纲_青河府少年_新作版.md`：按《沧元图》单集大纲的组织方式，重建新作第一卷的卷主线、23章推进、成长闭环和卷末悬念。

## 当前口径

- 篇级文件不再作为正式依据；前五篇以116章章节摘要和逐章覆盖审计为准。
- 正文不从摘要直接扩写，必须经过“文风校准—场景拆解—样章确认—分章写作—逐章核对”流程。
- 新小说不使用《沧元图》人物姓名；对照表中的原作节点只用于追踪迁移来源。
- 前五篇已展开到章节；正文首轮以剧情覆盖和叙事质量为优先，再按原作真实章节区间做字数校准。
- 当前前五章正文试读以最新“先收束水闸、再集中成长、篇末引出落星渡”改版为准：许宁是温柔克制的日常情感锚点，不是战斗搭档；苏萍不进入正文；林远在前五章完成厚土枪法到“听地”的阶段性成长，并在月试后获得参加落星渡镇魔队预备试炼的机会，动机是继续修炼和争取资源，不是查案。
- 第一卷新作结构稿见 `26_第一卷篇级大纲_青河府少年_新作版.md`；该文件是当前第一卷的结构参考，旧版迁移稿 `13_逐章迁移大纲_第一至第五篇_修订版.md` 保留为历史迁移档案，不作为本卷新作正文的唯一依据。
- 新增人物关系、桥接境界和本土化机制必须先写入 `00_迁移规则与新设定总表.md`，再修改篇级大纲。
- 角色新增、改名或关系变更必须同步 `09_角色对照表_原作至新小说.md`；地图扩展不得只增加地名，必须按 `10_地图迁移审计与扩展方案.md` 补齐区域秩序和剧情功能。
