## 当前口径

- 每篇 5—6 个详细剧情点，全部保留原篇主要剧情结果。
- 新小说不使用《沧元图》人物姓名；对照表中的原作节点只用于追踪迁移来源。
- 不展开到章节；本实验是篇级大纲，不与 500 万字、4500 字/章的正式创作规格混用。
- 新增人物关系、桥接境界和本土化机制必须先写入 `00_迁移规则与新设定总表.md`，再修改篇级大纲。
