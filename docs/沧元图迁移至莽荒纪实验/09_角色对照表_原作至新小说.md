# 《沧元图》原作角色—新小说角色对照表

> 用途：在阅读迁移后的新小说时，用本表反查某个新角色在原作中承担的剧情功能、人物关系和后续命运。
>
> 使用口径：左栏保留原作姓名，仅作为研究索引；新小说正文只使用右栏姓名。表中的“功能对应”不是简单改名，而是确认该角色在主线中承担的关系、冲突和结局是否一致。
>
> 状态说明：**已固定**表示新小说正文已有稳定对应；**功能位已定**表示剧情位置已经确定，但新小说还没有为该角色补出独立姓名；**待补写**表示原作角色的重要功能尚未完整落入当前迁移稿，不能把它误认为已经完成映射。

## 六、执行规则

1. 新增角色、替换角色或调整关系时，先改本表，再改 `00_迁移规则与新设定总表.md`，最后同步篇级大纲和详细对照表。
2. 发现新小说角色无法在本表找到对应项时，先判断是新增加的本土化角色，还是漏映射的原作角色；不得直接凭印象补写。
3. 同一原作角色只能有一个主映射；如果一个原作角色的功能被拆给多人，必须在“说明”中写明拆分原因和各自边界。
4. 同一新小说角色不得同时承接两个互相冲突的原作身份。例如：许宁只能对应柳七月，苏萍只能对应云青萍，不能因为两人都与林远有感情相关就互换。
5. 表中“待补写”不是缺陷掩盖，而是连续性检查清单；完成补名和插入剧情后，才可以改为“已固定”。
