# 青河府西府城地图与势力大纲

> 版本：v2.0
>
> 设定变更：本文件废止“青河县边缘县城”模型，改为《莽荒纪》式的大型部族统治中心。青河氏统治西府城及周边广阔领地，林家、何家、赵家、许家、顾家属于居住在外城的外族家族。林远前期不进入青河氏内城武殿，而是在外城与其他外族家族竞争，加入外城修炼势力，再逐步面对青河氏内部天才。
>
> 用途：为第一卷及前期正文提供可反复调用的地图、产业、人口、机构、家族和修炼势力。正文不一次性讲完本文件，而是让人物在出城、回家、进道院、参加比赛和处理妖患时逐步显露城市结构。

## 一、总体定位

### 1. 西府城是什么地方

西府城不是普通县城，而是青河氏在青河府北部建立的统治中心。

青河氏是一个拥有漫长传承的大型部族，麾下统领数百个大小部落、十余座城镇和大片山河。西府城既是青河氏的族地，也是青河府北部的军政、修炼和资源分配中心。

城中人分成三层：

1. **青河氏族人**：居住在内城，掌握府主、长老、军队和核心修炼资源；
2. **外族家族**：获得青河氏承认后迁入外城，负责粮运、药材、护运、工坊、商路和地方管理；
3. **附属部落与普通百姓**：分布在外城和城外领地，定期向青河氏缴纳贡赋、接受征调，也依靠西府城的市场和军队保护生活。

林家属于第二层。林家在本地经营多年，却不是青河氏族人，也没有进入内城的资格。林家拥有的资源和地盘，来自已故老祖林秋当年与青河氏府主共同守城后的赏赐与许可，而不是林家自身强大到可以占据一方。

### 2. 西府城与《莽荒纪》开局地图的借鉴关系

本设定借用《莽荒纪》初期“纪氏西府城”的功能结构，但不保留原人物和原名称：

| 借鉴功能 | 新作处理 |
|---|---|
| 大型部族统治中心 | 青河氏西府城，青河氏族人、军营和武殿集中于内城核心区域 |
| 内城 | 青河氏族地、府主府、长老府和核心藏书、宝库所在，外族不得随意进入 |
| 军营 | 青河氏军队和黑甲卫驻地，负责镇压外敌、妖患和部落叛乱 |
| 武殿 | 青河氏族人和直属部落少年修炼的场所，资源优于外城道院 |
| 外族竞争 | 林家、何家、赵家、许家、顾家等五家在外城争夺资源、商路和修炼名额 |
| 主角成长路线 | 林远先在外城道院站稳，之后才有资格和青河氏天才同场竞争 |

## 二、地理与城市规模

### 1. 周边环境

西府城建在青河东岸的一片高地上。青河从城西绕行向南，北面接着山口和河谷，东面是通往青河氏腹地的官道，南面连接农田、附属部落和其他城镇。

青河不是只有一条河道。主河两侧分出多条支流和灌渠，粮船、木排、药材船和军用运输船都要在西府城外的码头换装。城外五十里内有三处大型粮场、两座铁矿转运站和数十个受青河氏保护的村镇。

西府城的位置决定了它同时具有四种功能：

- 北方山地和妖兽活动区的防线；
- 青河府北部粮食、药材和矿材的集散地；
- 青河氏向外族分配资源和收取贡赋的管理中心；
- 年轻修士参加选拔、比赛和军队预备试炼的修炼中心。

## 三、城市格局

### 1. 内城：青河氏的核心族地

内城建在西府城东侧最高处，城墙高大，入口只有两处。外族没有府主召见、军务调令或特殊令牌，不得进入内城。

内城包含：

- **府主府**：青河氏府主处理军政、部落贡赋和外族封赏的地方；
- **长老府**：青河氏各支族老和闭关修士居住、议事之处；
- **青河氏祖地**：族谱、祖祠、血脉传承和族内大典所在；
- **内库与藏书楼**：存放青河氏核心功法、神魔炼体法门和历代战利品；
- **内城演武场**：青河氏嫡系和直属部落天才比试、选拔和接受长辈指点的地方；
- **府主亲卫营**：由黑甲卫和少量紫府修士组成，直接听命于府主。

内城不是林远前期可以随意进入的地方。它的存在主要通过外城公告、资源名额、比赛排名和偶尔出现的青河氏天才体现出来。

### 2. 军营：青河氏的武力核心

军营位于内城西侧，和外城之间有一道军门相连。军营分为三部分：

1. **黑甲卫营**：青河氏最精锐的直属战士，负责府主府、内城和重大妖患；
2. **府军营**：驻扎普通军队、先天境校尉和各部落征调来的战士；
3. **预备军校**：训练外族和附属部落中有天赋的年轻人，但名额由青河氏控制。

军营不会主动教导所有外族。外城道院取得好成绩的弟子，可以通过比赛或任务获得进入预备军校的资格，这正是外城修炼者向上攀升的重要通道。

### 3. 武殿：青河氏的修炼中心

武殿位于内城北侧，是青河氏模仿古老部族制度建立的修炼场所。

武殿拥有：

- 青河氏族人使用的练武场；
- 直属部落少年集中修炼的广场；
- 兵器库、兽血池和基础炼体室；
- 供族内长老讲道的讲武堂；
- 每四年举行一次的青河金令大典。

武殿的公开比赛允许少数外族天才参加，但外族享受不到完整资源。外族弟子即使赢下比赛，也只能获得外城席位、短期进入权或一份有限奖励，除非被青河氏长老看中，才可能真正进入内城体系。

### 4. 外城：五大家族和附属部落的竞争场

外城环绕内城，面积约为内城的六倍，分为三十六坊、五个大型仓区、两个码头区和一片外城演武区。

外城不是贫民区，而是一个拥有独立秩序的复杂社会。五大家族、商行、部落、外城道院和军队预备队都在此活动。

外城最重要的五类资源是：

1. **北河短运席位**：负责粮食、药材和军需在北河支流上的短途转运；
2. **外城仓区资格**：拥有仓库、货场和交易抽成权；
3. **兽血与灵药份额**：由青河氏按月分给外城势力，用于年轻修士修炼；
4. **道院修炼席位**：包括石室、地脉练功场、陪练和任务优先权；
5. **府军预备名额**：外族年轻人进入军营、镇魔队和青河氏武殿的通行资格。

林家失去的不是一座普通仓库，而是上述资源中的北河短运席位、外城仓区资格和部分兽血份额。何家、赵家、许家、顾家都希望重新分配这些资源，但每家争夺的目标不同。

### 林家宅院

林家宅院位于北河坊与旧城坊交界处，离北城门不远，离青河道院约半个时辰脚程。

林家虽然已经势衰，仍是外城五大家族之一，不是贫寒小户。主宅占地二十余亩，包含前后四进院落、祖堂、客院、账房、藏书楼、药房、仆役院和独立演武院；林远有自己的东跨院和练枪场。家中常年有管事、账房、医师、侍女、仆从、车夫和护院共六十余人，日常生活和普通修炼资源充足。

林家在北河坊拥有三座仓场、六条中型货船、十余辆货车和数处商铺，并承接粮食、石料与药材短运。林家的危机不是没有银钱生活，也不是立刻养不起仆役，而是在失去高阶战力后，青河氏准备重分北河短运、核心仓位、城务和道院名额；这些核心席位一旦失去，现有产业才会在数年内逐步萎缩。

林秋老祖生前为灵府圆满，凭战力、军功和与青河氏府主共同守城的交情替林家拿到北河核心席位。林秋去世后，林家家主林岳只有开脉圆满，沈墨也未进入灵府境；其余四家均有灵府境家主或族老坐镇，这一实力断层才是五大家族开始蚕食林家位置的根本原因。

## 五、青河氏与外族五家

### 1. 青河氏

青河氏是西府城的统治部族，不参与外城五家之间的普通生意竞争，但会决定资源分配、功法传授、军队名额和比赛规则。

- **府主青河烈**：元神道人层次，长期坐镇内城，负责青河府北部防线和部族秩序；不直接处理外城小事。
- **大长老青河山**：紫府圆满，负责族内资源和武殿事务；重视青河氏血脉天才，对外族天才保持观察。
- **军营主将青河重**：紫府后期，长期驻守北方山口；性格强硬，认为外族只有在战场上证明自己才配得到资源。
- **武殿殿主青河远**：紫府中期，负责族内少年、直属部落和金令大典；不喜欢外族挑战青河氏的权威。

青河氏内部也有嫡系、旁系和直属部落之分。青河氏天才之间同样存在竞争，但他们竞争的资源层次远高于外城五家。林远前期只能从外城看到他们的背影，直到在大型选拔或战场任务中与他们正面对上。

### 3. 五家竞争规则

五大家族不是一个联盟，而是五个彼此合作又彼此争夺的外族势力。青河氏每年根据外城比试、军务贡献、商路税额和妖患处理情况，重新分配外城资源。

每年竞争分为三层：

1. **家族总评**：比较各家上缴贡赋、商路贡献、城防任务和伤亡情况；
2. **年轻弟子排名**：五家年轻修士参加外城擂台、道院月试和实战任务；
3. **核心席位争夺**：排名前列者争夺兽血池、地脉练功场、外城道院石室和府军预备名额。

林远前期的成长，必须同时产生三种压力：

- 输给外城家族弟子，林家会丢掉一部分现实资源；
- 赢过外城家族弟子，他只能得到外城认可，还不能进入青河氏核心；
- 面对青河氏天才时，即使实力相近，也会因为功法、血脉、兵器和陪练资源不同而处于劣势。

这样可以保留《沧元图》中五个家族相互竞争的剧情功能，同时增加《莽荒纪》式的部族等级压力。

## 六、外城修炼势力：青河道院

### 1. 定位

青河道院位于外城演武坊，是青河氏承认但不直接控制的外城修炼势力。它主要吸收外族家族、附属部落和普通百姓中的修炼天才，为外城培养护卫、商路武者、镇魔队预备成员和军营候补。

青河氏内城有自己的武殿，外族不能把青河道院当成进入内城的捷径。青河道院只能提供基础功法、实战训练、比赛资格和有限资源，真正的高阶传承仍掌握在青河氏与更大的修炼宗门手中。

### 2. 院长与教习

- **院长陈观**：紫府圆满，出身外城普通武者家庭，曾是青河氏军营的外族校尉，因在北方山口守战中立功，退役后被允许建立青河道院。他不属于五大家族，最看重弟子能否在实战中活下来。
- **枪术教习张平**：先天境圆满，负责基础枪术、步法、承力和陪练；只指出动作问题，不代替弟子悟道。
- **镇魔教习魏安**：先天境后期，曾加入青河氏正式军队，后负责外城任务墙和预备试炼；熟悉北河、浅山和旧阵基。
- **外院执事**：负责家族名额、资源兑换、伤亡记录和比赛秩序；他们可以偏向青河氏，却必须公开执行外城排名规则。

### 3. 道院层级

| 层级 | 人数与功能 |
|---|---|
| 外院 | 约一千名弟子，学习炼体、兵器、身法、妖患常识和基础阵法。 |
| 内院 | 约一百二十人，能够稳定使用真气并参与外城任务。 |
| 内院前十 | 享有石室、陪练、兽血兑换和外城五席争夺资格；林远开局为第九。 |
| 外城榜首 | 顾长安长期占据，代表外族年轻修士的阶段性最高标准。 |

青河道院每月举行一次内院月试，每年与五大家族共同举办外城排名战。排名靠前者可以参加青河氏军营举办的预备试炼，但不等于直接成为青河氏族人。

## 七、城防、水闸与妖患体系

### 1. 城防分层

西府城有三道防线：

1. **外城城墙和四座城门**：由外城巡守、五家护院和部分府军共同负责；
2. **内城城墙与军营**：由青河氏黑甲卫和府军负责；
3. **北方山口与河流防线**：由青河氏军营、附属部落和镇魔队轮换驻守。

外城的水闸不是专门用来守妖的设施，而是北河坊的排水工程。它平时负责把低洼街巷和仓区周围的积水排入青河，河水上涨时则防止倒灌。水务所的水工负责看水尺、检查闸门和手动螺杆，青河道院弟子只按轮值制度协助巡查，不会常年驻守排水暗渠。

### 2. 北河排水闸

北河排水闸在外城北门外两里，外侧连接青河，内侧连接沿北河坊仓区铺设的排水暗渠。它不是三道分工不同的大闸，而是由外侧挡水栅、一段有顶且在闸门外侧拐弯的排水暗渠和内侧截水闸组成的小型排水设施。内截水闸上方设有手轮台，台上的火把只能照到闸板前几步，暗渠深处看不清人和妖物；城内侧另有一条沿渠边修出的窄石道，供检查和应急通行。

正常情况下，城内积水向外排出；河水上涨时，外侧挡水栅和内截水闸关闭，防止青河倒灌。内截水闸由手动螺杆启闭，手轮台旁设有水务轮值棚、水尺和简易烽火台。夜间通常只有两名水工值守，遇到汛期才会增加人手；道院弟子参与的是外城巡查和应急协助，不是专门守卫暗渠。

北河排水闸周围分布着：

- 林家三座仓场和六条货船常用的泊位；
- 何家控制的粮场支仓；
- 赵家护运队的换马棚；
- 通往北方山口的堤道；
- 青河氏军营设置的临时军需转运点。

第一卷开篇的水妖并不是从主河道主动攻击一座大型拦河闸，而是在河水上涨时冲破外侧挡水栅，进入内截水闸外侧一段有顶、弯折的暗渠。前半段战斗中，林远只能隔着闸板观察水花、撞击和偶尔伸出的爪子；直到妖兽撞破闸板下方的缺口，半截身体冲到城内侧，他才与妖兽真正近身交手。

因此第一章的水妖撞闸不只是一次普通城防事故：它会同时影响外城粮仓、五家短运、军需转运和北方防线。但这次危机只用于展示林远的枪法和判断，不能在第一章立刻升级为黑潮会追凶线。

### 3. 妖患响应

- 小型凡妖进入河道：水工和轮值弟子先处理；
- 先天境妖物袭击外城：外城道院、五家护院和镇魔队预备成员协助；
- 妖将或开灵妖族组织袭击：由青河氏军营和正式镇魔队接管；
- 妖王或大型部落战争：由青河氏长老、府主和更高层势力决定。

外族家族可以参与防守，却不能自行调动青河氏军营。林远越往后提升，越需要从“替林家守住资源”走向“获得青河氏军营和更高势力的认可”。

## 九、连续性硬约束

1. 主角开局所在地点统一称为“青河府西府城”或“西府城外城”，不再称“青河县城”。
2. 林家、何家、赵家、许家、顾家均为外族家族，不得写成青河氏嫡系。
3. 青河氏内城、军营和武殿拥有明显高于外城的资源，但外族天才仍然可以通过比赛、军功和任务进入更高层竞争。
4. 林远前期加入的是外城青河道院，不是青河氏内城武殿；后续获得武殿或军营资格必须有明确成绩和代价。
5. 五家竞争保留，但五家不是统一阵营；每家争夺的资源、年轻天才和利益不同。
6. 林家拥有北河短运资格、三座仓场、六条货船、车队和药材代运生意，但不掌握完整粮道或整个西府城河运；危机是核心席位和稳定货源被逐步侵蚀，不是家业已经败光。
7. 林秋老祖的旧关系只能为林家争取到外城席位，不能让林家直接进入内城或获得青河氏核心传承。
8. 青河氏天才必须拥有更好的资源、功法或血脉，但不能无理由压制所有外族；林远需要通过比赛和实战证明自己。
9. 城主失踪、搬往白河县和青河县县城秩序崩溃等旧设定全部废止，新的主要矛盾是外族资源竞争、青河氏等级压力和北方妖患。
