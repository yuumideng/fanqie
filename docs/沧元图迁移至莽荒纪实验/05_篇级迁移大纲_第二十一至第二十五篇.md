# 篇级迁移大纲：第二十一至第二十五篇

## 第二十一篇 妖圣通道

### 1. 黑魔殿狩猎黑龙星

林远在黑龙星修炼三百余年，无尽刀达到洞天圆满，云雾龙蛇身法接近天地境，却始终无法创造帝君级极限绝学。黑魔殿因黑龙老祖寿元将尽，关闭黑龙星并狩猎上万名修行者。林远伪装成普通尊者随众逃亡，遭两名帝君追杀时被迫暴露实力，以雷霆星辰子一击灭杀其中一人，再用虚空挪移符逃出黑魔殿大阵。

### 2. 混洞神体与寂灭刀

林远在时空长河中发现一座超大型混洞，以混洞规则重新锤炼肉身，创造“混洞神体”，肉身开始接近帝君圆满。随后他在混洞边缘参悟出寂灭刀，把混洞深处的毁灭和无尽刀的速度结合，形成一道无声无息、斩灭因果和元神的刀光。林远终于明白，自己不能只追求“更快”，还必须让速度有一个能够承载毁灭的终点。

### 3. 金羽帝成劫境与困守混洞

金羽帝从妖祖遗府归来，成为三劫境大能，携带妖族帝君级秘宝追杀林远。林远借混洞规则和雷霆星辰子不断转移，与金羽帝在混洞中周旋数百年。金羽帝毁掉周围时空，封锁所有出口，林远不得不把真身藏入混洞核心，以自身规则吞吸混洞力量。长久困守让他获得一线突破机会，也让金羽帝误以为只要耗尽时间就能获胜。

### 4. 妖圣通道出现

三界世界间隙扩大到足以容纳五重天妖王，黑潮三帝君和金羽帝决定同时发动最终战争。赤龙、玄重两名妖圣穿过通道，六百余名妖王从五处连接点杀入三界。林安坐镇玄元道庭，林远三界真身无法直接赶到域外，八尊元神分身同时守住八方。林远以元神世界笼罩五处连接点，把一百九十三名妖王全部擒下，黑袍裴隐和金甲使者被当场抹杀。

### 5. 两条真身各自突破

域外真身在混洞深处悟出帝君级极限绝学，突破原初境，成为真正帝君；三界真身则借元神星辰和雷霆大阵跨入元神八层前的劫境门槛。两尊真身同时成长，第一次让林远拥有了分别承担域外和三界危机的能力。黑潮妖族的战争彻底失败，林远绘成《脊梁》，把三界所有坚持到最后的凡人与修行者画进其中。

**篇末状态**：域外林远混洞境晋入帝君；三界林远成元神八层前的半步劫境；妖圣通道计划失败；金羽帝暂未陨落。

## 第二十二篇 劫境

### 1. 三界妖王清剿与林安成长

林远以元神世界控制三界，将剩余妖王分批镇压、收服或消灭。林安继承轮回传承后独自修行，练成六门洞天级绝学，却始终无法自创真正的尊者道路。林远没有替儿子解决瓶颈，只把玄元道庭的资源和历代战录开放给他。林悠成神魔后开始经营道庭事务，下一代家族逐渐脱离父亲的庇护。

### 2. 蛇魔星与景云洞主

域外真身追查黑魔殿在神女河域的据点，发现蛇魔星长期劫掠修行者。林远布下阴阳大界阵，先灭掉八首吞星蛇的两具四劫境分身，再迎战五劫境景云洞主。景云化作三万里长的吞星巨蛇，以吞吸、尾影和虚空吼三种杀招围攻，林远以寂灭刀伤其心灵，血刃盘割裂其真身，最后用阵法困住景云。景云以三百五十五名族人和三万方宝物换取追随一万年，林远接受，建立第一支域外追随者队伍。

### 3. 八百年参悟虚空图录

林远在东宁城建立交易城，收下庞风、钟毓两名三劫境追随者，邀请秦岳到域外修行。八百年间，他从《虚空图录》中理解空间规则，把云雾龙蛇身法推到五劫境层次，形成覆盖九亿六千万里的空间领域。雷霆、空间和寂灭三种规则已经出现融合迹象，林远开始感应第六次元神天劫。

### 4. 林安有子与傅穗邀约

林远感应到遥远泰东河域出现与林安相连的血脉气息，确认儿子已经有了孩子，却找不到其所在的八劫境秘境。域外苍盟成员傅穗邀请林远、乌沉魔君和天梦界陆虎共同探索魔山遗迹。林远答应同行，为的是寻找心灵修行机缘和渡劫方法；陆虎则提醒众人，魔山提供的好处很可能带着无法偿还的代价。

### 5. 第六次天劫前的准备

林远把九劫雷砂悬赏挂在永恒楼，以八劫境秘宝换取一粒雷砂，准备炼制世界秘宝。星空界的六劫境唐虞接下交易，得到无量之心，林远则将九劫雷砂送回三界。雷山融入元神世界后，林远的元神稳定性大幅提升。与此同时，林安在坤云秘境中被刚刚突破六劫境的石翁发现，毁掉真身后带妻子龙兰和儿子林御逃回三界。

**篇末状态**：林远帝君级域外真身，三界真身即将渡第六次元神劫；掌握三种五劫境规则；林安成为劫境；林御身份伏笔启动；林远准备救援坤云秘境。

## 第二十三篇 东宁城

### 1. 坤云秘境救援

林远传送进入坤云秘境，在地界找到没有背景的孙子林御，没有直接暴露全部身份，而是以家族令牌相认，传授《无量剑心》并留下三枚不死符。石翁控制龙兰，以神龙族百万族人威胁她寻找林御。林远先在地界斩杀杜忧魔祖，解除龙兰元神控制，再进入界府与石翁约战，以秘境归属换取族人生路。

### 2. 六劫境大战石翁

天界战场上，林远分化八尊元神，以雷泽图布下八百万里雷霆大阵；石翁化作顶天立地的百臂巨人，数百条手臂同时轰击。林远用十三寰宇珠吞吸雷泽之水，魔锥持续冲击石翁意识，使其力量无法集中。石翁以赤色血神柱破阵，林远只得从界府取出八劫境秘宝天罚图，雷霆天罚击碎血神柱并灭杀石翁的坤云真身。

### 3. 掌控坤云秘境

林远花五年炼化界府，成为坤云秘境的新主人，把秘境作为三界尊者修炼和培养下一代的场所。坤云秘境七位五劫境强者向他效忠，林安负责日常管理。林远收取黄玉巢、白珠、黑沙和九叶草等奇珍，总价值超过五十六万方域外元晶，建立起足以支持三界数百万年发展的资源库。

### 4. 家人延寿与许宁苏醒

林远用秘境宝物换取火源液、世界树果实和大量延寿奇珍，先唤醒沉睡两百六十四年的许宁，再唤醒林岳、苏晚、许河和林悠。许宁服下火源液后血脉纯化，寿元增加到四千余年；父母则恢复尊者级生命。全家聚餐时，林远绘成《圆满》，心力第一次不再来自战争和失去，而来自完整的家庭。

### 5. 因果杀金羽帝失败与再入魔山

林远以金羽帝血液为凭依，通过天罚图攻击妖祖洞中的金羽帝。金羽帝已经走上妖魔化道路，依靠妖祖洞削弱因果，肉身崩解后重新聚合。林远判断自己仍缺少彻底杀死三劫境的力量，决定渡劫成功后再请更高层强者出手。随后林远再次进入魔山心灵道路，获得界祖赠予的《永恒之路》，准备迎接第六次元神天劫。

**篇末状态**：林远六劫境前的元神强者；成为坤云秘境主人；许宁和家人全部苏醒延寿；金羽帝仍活；林远获得《永恒之路》。

## 第二十四篇 魔山

### 1. 四人组队进入遗迹

林远购买混洞珠、万龙阵和紫雷刀，与傅穗、乌沉魔君、天梦界陆虎进入魔山遗迹。遗迹世界压制极强，四劫境会被活活压死，五劫境才有资格进入。林远放出三尊元神分身探路，连续斩杀多头禁忌生物，发现这些生物并非守卫，而像是被某种力量驱赶到山顶。

### 2. 三条道路

魔山山顶有三条晶玉道路：第一条让人持续顿悟，第二条让人附身六劫境大能，第三条传来断断续续的心灵声音。傅穗选择顿悟，陆虎和乌沉选择附身，林远选择心灵道路。林远判断，自己已经有规则和宝物，真正缺的是能承载劫境力量的心灵意志。

### 3. 三种代价

傅穗在顿悟道路上十五年掌握六劫境规则，却因听见山顶字符而元神崩溃，回乡后必须长期服药，心性越来越暴烈。陆虎附身近万名六劫境大能，感悟彼此冲突，最终自毁真身回天梦界接受百世梦境；乌沉只附身六名大能，却发现道路扭曲，选择自毁离开。三人的遭遇证明魔山给的“捷径”都会向修行者收取代价。

### 4. 林远走心灵道路

林远十年走过三千里，心灵意志连续五次蜕变，压迫越来越轻，却每次间隔更长。走到万里时，山顶声音认可他为魔山普通成员，允许他从九座河域出口进出。林远没有继续强行登顶，而是先离开魔山，回到东宁城整理所有雷霆、空间和寂灭感悟。

### 5. 突破六劫境与炼制世界秘宝

林远以心灵五次蜕变承载雷霆规则，第二年掌握六劫境雷霆规则，生命层次质变，能够化身百亿里雷霆。为迎接第六次元神天劫，他用九劫雷砂炼成雷山世界秘宝，融入元神世界。此时林安在坤云秘境遭石翁余党入侵，逃回三界求援，林远携雷泽图和雷霆秘宝立即传送前往。

**篇末状态**：林远掌握六劫境雷霆规则，仍未渡劫；成为魔山普通成员；世界秘宝雷山炼成；林安和龙兰遭遇坤云秘境危机。
