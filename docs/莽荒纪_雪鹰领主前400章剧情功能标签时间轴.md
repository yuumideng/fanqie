# 《莽荒纪》《雪鹰领主》前400章剧情功能标签时间轴

> 用途：为两部作品的剧情杂糅建立可核对的功能账本。范围为两部作品各自第1—400章。这里的“事件段”不是逐章梗概，而是把跨章节的完整事件合并后，再拆成可替换的剧情功能单元。后续融合大纲必须以本文件的标签对应关系为依据，不能只凭印象拼接桥段。

## 一、标签体系

### 1. 叙事功能标签

| 标签 | 专业含义 | 判断标准 |
|---|---|---|
| `设定建立` | 建立世界、家族、组织、修炼规则或资源规则 | 读者在此获得此前没有的基础认知 |
| `人物建立` | 第一次明确人物身份、性格、能力或关系 | 人物后续行为需要依赖本段信息 |
| `矛盾启动` | 让主线冲突从潜伏状态变成行动 | 敌人出手、资源暴露、亲人受害或任务下达 |
| `压力升级` | 提高已有矛盾的范围、强度或代价 | 敌人变强、时间缩短、地图扩大、退路减少 |
| `信息揭示` | 回收旧伏笔或揭开敌我关系、身世和世界真相 | 改变读者对前文的理解 |
| `事件反转` | 把原有目标、敌我、胜负或身份重新定义 | 事件方向发生不可逆变化 |
| `高潮结算` | 通过战斗、比赛、审判或选择完成阶段性结果 | 一个主要矛盾得到明确结果 |
| `过渡换图` | 把主角从旧地图、组织或目标送入新阶段 | 旧阶段收束并出现下一阶段入口 |
| `伏笔埋设` | 当前不解决、为后续回收保留因果 | 后续必须能解释其功能 |
| `阶段钩子` | 章末或卷末提出下一阶段明确问题 | 读者知道接下来要追什么 |

### 2. 主角成长标签

| 标签 | 含义 |
|---|---|
| `成长-基础` | 选择功法、武器、师父或第一条主修路线 |
| `成长-积累` | 长期闭关、训练、读道、任务积累，不立即突破 |
| `成长-悟道` | 从战斗、观察、情感或传承中理解力量本质 |
| `成长-突破` | 境界、身体、元神、真意或神心发生不可逆提升 |
| `成长-验证` | 新能力在比赛、追杀、任务或战争中被验证 |
| `成长-失败` | 主角正面落败、道路受阻或重要目标失败 |
| `成长-重建` | 旧路线被打断后重新组合能力和目标 |
| `成长-隐藏轴` | 主角此前不被外界判断的第二力量路线公开或升级 |
| `成长-身份` | 从家族子弟进入宗门、组织、世界或文明核心 |
| `成长-目标` | 主角的守护、复仇、求道目标发生层级变化 |

### 3. 世界与剧情资源标签

| 标签 | 含义 |
|---|---|
| `地图-扩张` | 新地域、秘境、世界、星域或大世界开启 |
| `组织-进入` | 加入宗门、学宫、军团、酒馆、师门等正式组织 |
| `组织-竞争` | 组织内部排名、考核、弟子竞争或资源竞争 |
| `组织-战争` | 组织之间进入全面冲突 |
| `资源-获得` | 取得功法、法宝、神通、传承、特殊生命或重要资源 |
| `资源-代价` | 获得资源同时承担债务、追杀、限制或身份暴露 |
| `家族-守护` | 家族、父母、兄弟、族人被保护或遭遇危机 |
| `情感-发动机` | 感情事件直接触发主角修炼、突破或目标变化 |
| `敌对-个人` | 单个敌人或小团体的阶段性冲突 |
| `敌对-组织` | 宗门、魔神会、雪龙山、血神教等组织性敌对 |
| `世界-危机` | 三界、夏族世界、世界群或宇宙层面的危机 |

### 4. 爽点与节奏标签

| 标签 | 含义 |
|---|---|
| `爽-首秀` | 主角第一次公开展示远超身份的实力 |
| `爽-同级压制` | 在规则相近的对手中稳定取胜 |
| `爽-越级` | 低境界击杀或击败高境界强敌 |
| `爽-隐藏底牌` | 对手误判主角，主角用隐藏路线反杀 |
| `爽-连续赛` | 多场考核、擂台、任务或试炼连续兑现能力 |
| `爽-反杀` | 前段失败或被追杀，后段以新能力完成回收 |
| `爽-夺冠` | 在公开排名、天才战或大会中获得第一 |
| `爽-传承` | 获得高阶神通、师门或特殊传承 |
| `爽-地图跃迁` | 从小地图成功进入更高大地图 |
| `代价-失去` | 亲人死亡、道侣受伤、路线受阻或资源损失 |

## 二、《莽荒纪》前400章事件功能时间轴

### 1. 第1—18章：燕山纪氏起步

**事件序列**：

1. 纪宁转世进入纪氏西府，地府、女娲图、父母和燕山纪氏建立；纪一川不使用入阶法宝的异常埋下紫府旧伤伏笔。
2. 纪一川为纪宁选择神魔炼体，纪宁兼修赤明九天图、箭术、风翼遁法和滴水经，六年苦修达到人剑合一。
3. 困笼训练逼出战斗本能，翼蛇屠戮金刀部落，万剑城购买北冥剑，翼蛇幼子赤芒被捉，人与妖的个人仇恨启动。

**标签**：`设定建立` `人物建立` `家族-守护` `成长-基础` `成长-积累` `伏笔埋设` `矛盾启动` `阶段钩子`

**主要功能**：把纪宁从“有天赋的转世者”变成“有家庭和家族责任的修炼者”；同时建立女娲图这一隐藏神魂轴。

### 2. 第19—36章：东山大泽与翼蛇追杀

**事件序列**：

1. 纪宁调查金刀部落惨案，追踪翼蛇进入东山大泽，被翼蛇一击断臂；纪一川出手迫退翼蛇，纪宁伤愈后斩杀赤芒，金剑大典一对七公开扬名。
2. 纪宁进入东山大泽猎杀妖兽，首杀水犀王，遇到空青蛇王和铁木占布置的阴阳二气阵，陷入人族修士与妖族同时利用的局面。
3. 纪宁在池边静坐悟道，突破先天神魔之躯，以水火莲花和滴水穿石斩杀犴兽、铁木占，完成第一次“失败—悟道—突破—越级反杀”。

**标签**：`矛盾启动` `压力升级` `成长-失败` `成长-悟道` `成长-突破` `成长-验证` `爽-首秀` `爽-越级` `爽-反杀` `敌对-个人`

**主要功能**：给主角真实失败和第一次大反杀，证明纪宁的悟道来自自身观察，而不是传承灌输。

### 3. 第37—47章：春草之死与普通人的复仇

**事件序列**：

1. 纪宁归途修炼风翼遁法，在黑牙部落得知童年伙伴春草为保护弟弟青石服毒自尽。
2. 纪宁调查江禾恶行，追到江边部落，杀死江禾并公开曝尸三日，完成第一次以强者身份为普通人主持公道。
3. 纪宁重新前往翼蛇湖，主动向翼蛇宣战，修炼目标从“证明自己”增加“保护身边人和追讨责任”。

**标签**：`人物建立` `家族-守护` `情感-发动机` `成长-目标` `敌对-个人` `高潮结算` `阶段钩子` `代价-失去`

**主要功能**：将主角的热血和责任感具体化，避免纪宁只为个人机缘升级。

### 4. 第48—65章：水府三关、小千剑阵与翼蛇决战

**事件序列**：

1. 纪宁在翼蛇湖发现水府，经历金甲兵将、道兵甲铠和黑毛碧眼怪物三关，女娲图带来的神魂优势转为神念御物能力。
2. 纪宁取得水府信符、《小千剑阵》和神魔血炼术，三柄北冥剑完成提升，表面剑法之外的神念、阵法路线成形。
3. 纪宁以水火莲花、小千剑阵和神念配合击杀翼蛇，个人仇恨结算，水府资源和纪宁新战力同时暴露。

**标签**：`地图-扩张` `资源-获得` `成长-隐藏轴` `成长-验证` `爽-隐藏底牌` `爽-越级` `爽-传承` `高潮结算` `阶段钩子`

**主要功能**：建立《莽荒纪》的第一套“表面剑道+隐藏神念+阵法”爽点模型。

### 5. 第66—80章：族人失踪、孛子善和应龙卫入口

**事件序列**：

1. 黑雾迷阵中二十三名纪氏先天生灵失踪，孛子善以万鬼幡炼制邪法，纪宁从奴印、人数和驯兽痕迹反推敌人布局。
2. 蒙鱼、小七等人被囚，纪宁中蚀心散，在毒发和厉鬼攻击中以《阵法九卷》破阵，女娲图净化神魂。
3. 纪宁以小千剑阵斩杀孛子善，木晓真人确认其神魂潜力，赠应龙卫令牌，纪宁获得进入大夏官方体系的资格但暂不离开家族。

**标签**：`家族-守护` `矛盾启动` `压力升级` `成长-隐藏轴` `成长-验证` `爽-反杀` `组织-进入` `资源-获得` `阶段钩子`

**主要功能**：把个人反派升级为组织入口，并第一次证明女娲图不是背景装饰。

### 6. 第81—100章：母亲死亡、五年苦修和紫府之战

**事件序列**：

1. 尉迟雪病危，水府无法救治，纪一川揭示尉迟山旧案；纪宁陪母亲走完最后时间，风翼遁法和临终悟道成为情感回收。
2. 纪宁在翼蛇湖苦修五年，神融天地、参悟万剑曲；纪墨求师，火龙道人突破地仙，元石矿脉暴露。
3. 雪龙山分支威逼纪氏，纪宁与纪九火布阵击杀三名紫府修士，元液开辟紫府；雪龙山召集援军，纪宁进入水府深层。

**标签**：`代价-失去` `情感-发动机` `成长-积累` `成长-悟道` `成长-突破` `家族-守护` `敌对-组织` `组织-战争` `地图-扩张` `阶段钩子`

**主要功能**：完成前期家庭情感收束，把地方家族冲突推向雪龙山和安澶侯府。

### 7. 第101—138章：水府四殿、神识突破和纪一川离世

**事件序列**：

1. 星辰殿五年读道，纪宁悟出雨水剑域；战神殿的木桩和黑豹试炼暴露战力边界，珍宝殿让其选择冥龙锁天阵。
2. 雪龙山十九名紫府修士和紫府灵兽进攻牛角山，纪宁以冥龙锁天阵、雨水剑域和小千剑阵连续斩杀，击杀童玉却被万象许离真人重创。
3. 纪宁进入神通殿，绝境中开天眼显神识，取得《摘星手》和寂灭戮魔剑；返回一招击杀许离、农子道，但纪一川战后离世，北山百微庇护纪氏，纪宁离开燕山。

**标签**：`地图-扩张` `成长-积累` `成长-悟道` `成长-突破` `成长-失败` `成长-隐藏轴` `爽-连续赛` `爽-隐藏底牌` `爽-反杀` `代价-失去` `家族-守护` `过渡换图`

**主要功能**：形成第一次大型战争高潮，同时完成“主角必须离开故乡”的换图。

### 8. 第139—179章：安澶城、黑白学宫和理论殿

**事件序列**：

1. 纪宁救下孟氏一行，进入安澶城，在无忧洞宝会上以雨水剑域击败白巫，取得资源并公开扬名。
2. 纪宁通过雷阵和守关挑战，进入黑白学宫，拜殿才仙人为师，选择北冥峰，接触黑白图和北行仙人三尺剑。
3. 纪宁以紫府巅峰挑战理论殿老弟子和万象弟子，剑心通明、三尺剑第一招成形，最后败给转世仙人余薇。

**标签**：`过渡换图` `组织-进入` `组织-竞争` `资源-获得` `成长-身份` `成长-悟道` `成长-验证` `爽-首秀` `爽-同级压制` `爽-连续赛` `成长-失败`

**主要功能**：把主角从地方天才变成大夏范围的竞争者，并建立公开比赛体系。

### 9. 第180—213章：应龙卫考试、万象突破和妖族伙伴

**事件序列**：

1. 殿才传授《撼神术》，纪宁领悟三尺剑第二招，购买大量飞剑和伏羲棍阵，准备参加应龙卫考试。
2. 狱山大荒泽中，纪宁救出人族奴隶，遭六名万象修士围杀，以撼神术、剑阵和神念连续反杀，突破万象真人并出现三大异象。
3. 空青蛇成长为纪青青，龙鲸追杀中突破元神，古神苏醒镇压龙鲸，纪宁正式加入应龙卫。

**标签**：`组织-进入` `组织-竞争` `成长-隐藏轴` `成长-突破` `成长-验证` `爽-连续赛` `爽-越级` `地图-扩张` `敌对-个人` `资源-获得`

**主要功能**：完成稳定的多力量战斗体系，建立官方任务入口。

### 10. 第214—252章：复仇、九莲分离和雪羽道人

**事件序列**：

1. 纪宁清算余桐、残月真人和水易，冬七被雪龙山保护，个人仇线从杀人变成对宗门保护体系的长期追索。
2. 纪宁苦修领悟三尺剑第三招和风之道域，与九莲从并肩作战发展为道侣；陈金挑战失败，九莲被带回万莲洞。
3. 九年后九莲重逢，纪氏扩张触发雪龙山分支冲突，纪宁击退元神圆满雪羽道人；仙缘大会钩子出现。

**标签**：`敌对-组织` `情感-发动机` `成长-积累` `成长-悟道` `成长-验证` `家族-守护` `爽-越级` `代价-失去` `阶段钩子`

**主要功能**：用关系分离和家族冲突制造中段沉淀，不让主角只靠连续战斗升级。

### 11. 第253—281章：无间仙府、少炎农背叛和大道域境

**事件序列**：

1. 少炎农邀请纪宁进入无间仙府，众人进入藏宝、仙草、道兵、道藏等区域，资源、神通和身份竞争同步展开。
2. 少炎农暴露真实目的，以尉迟旧案、余薇和九莲为诱饵，将寻宝活动变成封闭追杀；同伴被分散，纪宁失去正常退路。
3. 纪宁在极端压力中领悟大道域境，击杀雪红衣、少炎农和项柳方神魂，送走同伴后进入水府避祸。

**标签**：`资源-获得` `资源-代价` `组织-竞争` `事件反转` `压力升级` `成长-悟道` `成长-突破` `爽-隐藏底牌` `爽-反杀` `代价-失去` `过渡换图`

**主要功能**：把资源试炼反转成背叛，完成主角由“同门天才”向“被大势力追杀者”的身份转换。

### 12. 第282—317章：第二元神、雪龙山覆灭和三界危机

**事件序列**：

1. 纪宁完成雨水道、第二元神和元神圆满，携带水府行动；天宝山交易会和浮云仙人刺杀验证第二元神价值。
2. 尉迟雪公主与纪宁相认，夏芒氏调动金甲禁军清剿雪龙山，冬七死亡，父母仇线阶段回收。
3. 少炎氏残党以蚀道寒煞压制纪宁元神和道域；六道轮回毁灭、三界混乱和血神教活动被引出。

**标签**：`成长-突破` `成长-隐藏轴` `成长-重建` `信息揭示` `敌对-组织` `世界-危机` `家族-守护` `爽-反杀` `代价-失去` `阶段钩子`

**主要功能**：将《雪鹰领主》的“修炼道路被毒截断”机制放入《莽荒纪》的元神体系，制造全新的中段危机。

### 13. 第318—357章：仙缘大会、余薇记忆和一字剑斩

**事件序列**：

1. 一亿多名万象真人进入明月山水图，纪宁在蚀道寒煞未完全解除的状态下参与生存、争夺和淘汰。
2. 纪宁与余薇重逢并结伴，余薇觉醒前世记忆；夏芒奇重伤余薇，纪宁被迫用基础剑道、神念和第二元神作战。
3. 纪宁在极端情绪和道心压缩中领悟一字剑斩，击杀夏芒奇和飞雪道人，最终夺得第一，获得菩提邀请。

## 五、替换原则结论

依据标签后，真正应该被替换的不是“角色名字”，而是剧情功能：

1. 《莽荒纪》的前期家族、传承、复仇和剑道负责提供连续性。
2. 《雪鹰领主》的组织任务、公开竞争、修炼失败、道路重建和世界战争负责填补《莽荒纪》阶段之间的推动空档。
3. 同功能事件不叠加。例如水府、无间仙府、红石山都属于高阶遗迹，融合版必须给它们不同的功能，而不是连续安排三次寻宝。
4. 每一个从《雪鹰领主》移植的事件，都要回答四个问题：它替换了《莽荒纪》的哪一段功能？使用了哪些原有人物？新能力从哪里来？事件结束后主角的目标和地图发生什么变化？

下一份融合大纲应以本文件第四节的替换矩阵为约束，而不是继续沿用“《莽荒纪》原剧情+少量雪鹰桥段”的写法。
