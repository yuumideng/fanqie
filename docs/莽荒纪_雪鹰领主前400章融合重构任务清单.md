# 《莽荒纪》融合《雪鹰领主》前400章重构任务清单

> 用途：约束下一版实质融合卷纲的创作与验收。当前这份清单不是剧情正文，也不是融合结果；完成全部检查项后，才允许把新卷纲称为“融合版”。

## 一、任务目标

- [x] 以《莽荒纪》的世界、人物关系和力量体系作为承载基础。
- [x] 将《雪鹰领主》前400章的具体事件机制、人物功能、竞争结构和危机推进真正移植进来。
- [x] 不是在原《莽荒纪》剧情旁边添加解释，而是对部分原事件进行替换、重排或重构。
- [x] 前400章形成一条能独立阅读的新主线，不能只是两部作品的事件清单拼接。

## 二、硬性创作要求

- [x] 每卷保留明确的章节范围、卷主线、卷尾结果和下一卷钩子。
- [x] 每卷“主要内容”写3—7条，每条必须是完整的小剧情段落，说明人物、行动、冲突、结果和后续影响。
- [x] 每个雪鹰来源事件都必须标明：原作事件、迁移到莽荒纪的承载人物/地点、替换的原剧情功能、改编后的结果。
- [x] 不能把“训练压力、天才、越级、悟道、外部危机”等抽象功能单独算作雪鹰剧情。
- [x] 原《莽荒纪》能够独立解释的事件，一律标为基底；只有发生具体重构时，才标为融合改编。
- [x] 不直接使用《雪鹰领主》人物名、专有境界名、组织名和地图名；必须本土化承载。
- [x] 新增能力必须有来源、首次出现位置、使用限制、代价和后续成长路径。
- [x] 不凭空新增法宝、身份、感情信物、师门关系或地图；新增内容必须在前文引出并在后文回收。

## 三、融合比例要求

- [x] 不能出现“前十卷几乎全是原《莽荒纪》、后面只加一条毒术”的情况。
- [x] 至少四成卷内主要事件必须经过《雪鹰领主》具体剧情机制的替换或重构。
- [x] 每卷至少核对一次：本卷是否有真实雪鹰事件进入，而不是只在“主要融合功能”栏写概念。
- [x] 如果某卷没有实质融合，必须明确标记“未融合”，不得用功能类比伪装成融合。

## 四、连续性检查要求

- [ ] 角色检查：人物首次出场、身份、立场、关系、目标和离场结果前后一致。
- [ ] 力量检查：境界、功法、神通、法宝和隐藏路线的获得顺序与使用上限一致。
- [ ] 地图检查：每次换图都有原因、门槛、资源变化和新矛盾，不能突然跳图。
- [ ] 因果检查：先发生原因，再出现发现、判断和行动；不能提前知道尚未揭示的信息。
- [ ] 目标检查：主角每卷的修炼目标、家族目标、个人仇线和世界危机必须有先后层次。
- [ ] 爽点检查：比赛、试炼、突破、越级、反杀和身份提升必须有铺垫、规则、代价和结果。
- [ ] 伏笔检查：每个新增设定至少有引出、使用、回收三个节点。
- [ ] 删重检查：同一事件不能同时被原剧情和雪鹰剧情重复使用，除非明确说明两者被合并。

## 五、来源标记规范

- `[莽荒基底]`：原《莽荒纪》事件，未进行实质改写。
- `[雪鹰改编]`：具体取自《雪鹰领主》的事件机制，已换成莽荒纪承载方式。
- `[融合重构]`：保留《莽荒纪》的角色/地图骨架，同时对事件目标、过程、冲突和结果进行了实质重写。
- `[待补融合]`：当前仍是原剧情，不能计入融合比例，只用于提醒后续重构。

## 六、最终交付前的逐项验收

- [x] 先完成两部作品的前400章事件替换表，再写融合卷纲。
- [x] 每卷逐条回填来源，不允许写完后凭印象补标签。
- [x] 汇总所有 `[雪鹰改编]` 和 `[融合重构]` 条目，确认它们对应具体原作事件。
- [x] 抽查每卷至少一条：删除雪鹰来源后，剧情是否会失去关键推进；若不会，说明融合仍然不够具体。
- [x] 逐卷检查人物、力量、地图、因果和伏笔。
- [x] 统计融合比例，并把统计结果写入最终卷纲。
- [x] 最终文件开头明确写明：完成版、审计版或待重构版，禁止混用名称。
- [x] 未完成全部检查项前，不得把文件称为“仔细融合版”或“最终融合版”。
