## resources 目录说明（已纳入私人仓库）

`resources/` 存放五部原作的原文 txt 与按章分割产物。五部原文由项目所有者本人创作，当前仓库为私人仓库，原文及分析产物均纳入版本控制，用于本项目的研究、整理和创作规划。

- `吞噬星空.txt` / `莽荒纪.txt` / `飞剑问道.txt` / `沧元图.txt` / `雪鹰领主.txt`：原始文本
- `吞噬星空_分章/` 等：由 `tools/split_*.py` 按章切分生成的单章文件

在新设备上延续工作时，直接同步或克隆整个私人仓库即可，无需另行准备原文 txt。

## 大纲生成技术方案

当前工作流以各原作目录的索引、逐章大纲和 `_state/` 状态档案为准；历史技术方案已移入 `docs/归档/`。核心架构：

1. **按章分割**：`tools/split_*.py` 依据 `00_原文索引.md` 把原文切成单章文件，落盘可断点续传；
2. **单章读取 + 滚动状态档案**：每篇/集/卷维护一个轻量 `state.md`（人物境界/伏笔追踪/主线进度/近章摘要），替代全量原文上下文，控制上下文长度；
3. **篇级子Agent并行**：每篇/集开一个子agent独立处理，多篇同步生成；
4. **篇级聚合**：汇总逐章条目生成篇基本信息与篇主要内容。

## 项目规则（按任务读取）

接手只读 `AGENTS.md` 和 `docs/当前接手卡.md`。具体任务再按四级读取规则定位资料；大文件优先使用 `tools/query_material.py`。项目执行边界、原作事实边界和 Git 交付细则分别见 `项目执行规则.md`、`原作分析规则.md`，不在 README 重复维护。

README 的目录、进度和完成度是导航信息，不是本次任务的质量验收结果；需要核查时只核查用户指定范围。

用户说“提交”即执行一次业务提交、推送工作分支、快进合并并推送 `main`；`CHANGELOG` 不因补写推送状态追加提交，最终远程结果在交付回复中确认。除非认证、网络、权限或工具失败，不重复确认。

## 文档使用边界

当前工作主要使用以下正式产物，并包含新小说设计与剧情迁移实验档案：

- 五部原作目录中的 `00_原文索引.md`、逐篇/逐卷大纲和 `_state/`；
- `五书全量逐章分析附录.md`、`五书全量逐章特征数据.csv`、`五书全量逐章结构节奏爽点对比分析.md`。
- `docs/新小说设计基线_持续存档.md`：500万字新小说的规格、分卷方案和已确认力量体系。
- `docs/沧元图迁移至莽荒纪实验/`：将《沧元图》29篇剧情按顺序迁移到《莽荒纪》世界观的实验性篇级大纲、设定总表、角色对照表、详细对照表和地图扩展审计。
- `docs/原文专项摘录/`：按卷章标注的五部原作前300章主角技艺、灵魂与境界提升原文片段；《宇宙职业选手》因当前缺少可读取原文，暂未生成。
- `docs/沧元图迁移至莽荒纪实验/27_青河府西府城地图与势力大纲.md`：青河氏大型部族统治中心西府城的内外城格局、人口、产业、机构、外城五大家族、青河道院及其与青河氏武殿的关系。
- `docs/吞噬星空迁移至莽荒纪实验/`：将《吞噬星空》29篇剧情按原作节奏迁移到《莽荒纪》世界观，包含角色、地图、力量和29篇功能基准层。
- `docs/雪鹰领主迁移至莽荒纪实验/`：将《雪鹰领主》38篇剧情按原作节奏迁移到《莽荒纪》世界观，包含一一对应角色表、完整地图路线、力量体系、38篇功能迁移表和篇级详细大纲。
- `docs/莽荒纪前400章_分段人物成长与事件分析.md`：按完整事件段整理《莽荒纪》前400章的人物成长、修炼突破和事件推进。
- `docs/雪鹰领主前400章_分段人物成长与事件分析.md`：按同一颗粒度整理《雪鹰领主》前400章的人物成长、修炼突破和事件推进。
- `docs/莽荒纪_雪鹰领主_时间轴境界事件对照.md`：对照两部作品前期的时间轴、境界推进和事件推动。
- `docs/莽荒纪_雪鹰领主前400章剧情功能标签时间轴.md`：将两部作品前400章按叙事功能、成长、地图、组织和爽点建立可替换标签。
- `docs/莽荒纪基底融合雪鹰领主前400章_实质融合版详细卷纲.md`：当前采用的融合版前400章详细卷纲；以《莽荒纪》人物和世界为基底，依据标签矩阵吸收《雪鹰领主》的剧情推动机制。
- `docs/剧情创意记录_持续存档.md`：保存后续新作设计可复用的独立剧情创意。
- `docs/沧元图迁移至莽荒纪实验/` 中的 `13`、`14`、`15`、`21`、`22`、`23`、`25`、`26`、`27`、`30` 文件：当前采用的修订版迁移大纲、正文流程、审计报告、人物描写统计、地图势力大纲、第一卷篇级大纲和前五章校订正文。
- 迁移实验保留苏萍退婚角色等旧迁移档案供追溯；当前《沧元图》前五章正文试读已移除苏萍持续戏份，并将许宁收束为情感锚点和主角升级触发器，具体以实验目录中的最新正文和审计文件为准。
- `五书逐章分析_人力可读版/` 与 `五书战斗与修炼比赛场景统计.md`：面向人工阅读的分析版本及比赛场景统计。

已被替代的横向分析、旧技术方案、旧合并大纲和阶段性深度报告统一放在 `docs/归档/`，只用于历史查阅；当前正式工作范围限于五部原作分析及其汇总产物。
